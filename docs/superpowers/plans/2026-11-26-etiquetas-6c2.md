# Change 6c-2 · Weekly batch of doubtful tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Once a week (Monday, America/Santiago) Coni gets up to five doubtful tags in one batch: a line in Inicio
(«Tienes n etiquetas para revisar») leads to `/biblioteca/etiquetas/revisar`, where each card says why the tag is
there and offers «Está bien» or «Cambiar» with the 6c-1 editor; the 6c-1 log now records which mark row was touched.

**Architecture:** One migration adds `marca_id` to `correcciones_de_etiqueta` (the three 6c-1 functions write it), two
tables for the batch (read by Coni and WAV, written by nobody directly), a private `etiquetas_dudosas()` helper, a
private filler and `lote_de_la_semana()`, which builds the week's batch on Coni's first read and returns its items with
a derived `hecha`. A pure domain module (`lote-de-etiquetas.ts`) owns the card texts, progress, the Inicio line and how
an item becomes a card; one data module reads the batch and its claims. The page is a Server Component with one client
card per item that reuses `EditorDeEtiqueta` and the 6c-1 Server Actions.

**Tech Stack:** Next.js 16 App Router (Server Components + Server Actions), Supabase Postgres (RLS, `security definer`
plpgsql and sql), Zod, Tailwind v4 tokens, Vitest (unit with jsdom, integration against local Supabase), Playwright.

Spec: `docs/superpowers/specs/2026-11-26-etiquetas-6c2-design.md` (authoritative, approved by Federico).

## Ajustes a la spec

Places where the code does not match the spec. The plan follows the code and says so here; nothing is changed silently.

1. **WAV cannot open the page.** The spec says Coni or mantenedor, mantenedor read only, «`exigirConi` style guard used
   by the Biblioteca». `exigirConi` (`lib/sesion/coni.ts`) gives a 404 to anyone who is not Coni, mantenedor included,
   and no screen of the app has a read-only mode. The page uses `exigirConi` like every Biblioteca page and has no
   read-only variant. The database keeps the spec's rule (`lote_de_la_semana()` lets WAV read the batch without building
   it; tested), so a WAV screen can come later without a migration.
2. **The Inicio line is a reminder.** The merges line the spec points to is a `RecordatorioDeInicio` (`titulo`,
   `detalle`, `accion`) drawn by `LineaDeEstado`; it needs a detail and an action label. The plan uses title «Tienes n
   etiquetas para revisar» (singular «Tienes 1 etiqueta para revisar»), detail «Claude no estaba segura de estas.
   Confírmalas o cámbialas.» (singular «de esta. Confírmala o cámbiala.») and action «Revisar etiquetas». Like the merges
   line it counts as attention in Inicio's title.
3. **«Ver la afirmación» and back.** `volverDesde` only accepts an author, topic, material or hook page in `?desde=`. The
   plan extends it to `/biblioteca/etiquetas/revisar`, and «Volver» on the claim's page then says «Etiquetas para
   revisar».
4. **A per-network mark stored with `red = 'todas'`** never enters a batch: 6c-1 does not show it (plan 6c-1, decision
   14) and its functions refuse it (`red_invalida`).
5. **A claim hidden, excluded or deleted with «Deshacer» after its batch was built** no longer has doubtful tags, so its
   item counts as done (`hecha`) and shows no card. The spec's «done» rule does not mention it.
6. **A done item without a log row of hers** (for example change 7's reprocess takes a tipo out of `sin_clasificar`)
   says «Ya no está pendiente». The spec only lists «Confirmada por ti», «Corregida por ti» and «Ya no está».
7. **One more private function**, `llenar_lote_de_etiquetas(uuid, date)`, keeps `lote_de_la_semana()` short. Not granted.
8. **Inside one claim** the spec does not order two tags of the same motivo: the plan takes the field order of
   `CAMPOS` (tipo, evidencia, problema, solución, emoción, público, dato, caso, tipo de gancho), then the network, then the
   mark id.
9. **The card is not a `Panel`:** the 6c-1 editor is drawn on `piedra-alta`, and `DESIGN.md` forbids a panel inside a
   panel. The card is a bordered `article` and the editor opens inside it.
10. **«Cambiar» opens the 6c-1 editor already open** (two new optional props, `abrirAlMontar` and `alCerrar`). Its form
    also has «Está bien» and «Cerrar», as on the claim's page.

```ts
import { randomUUID } from "node:crypto"
import type pg from "pg"
import { CONI } from "./db"

/** The Monday of this week in America/Santiago, as the migration computes it. */
export const SEMANA = "date_trunc('week', now() at time zone 'America/Santiago')::date"
export const LOTE = "select posicion, afirmacion_id, campo, red, marca_id, motivo, hecha from public.lote_de_la_semana()"

export interface FilaDeLote {
  posicion: number
  afirmacion_id: string
  campo: string
  red: string
  marca_id: string | null
  motivo: string
  hecha: boolean
}

export async function uno(c: pg.PoolClient, sql: string, params: unknown[] = []): Promise<string> {
  const { rows } = await c.query<{ id: string }>(sql, params)
  const id = rows[0]?.id
  if (!id) throw new Error(`No se creó: ${sql.slice(0, 60)}`)
  return id
}

/**
 * As postgres, inside the test's transaction (always rolled back): no batch, and every claim already in the local
 * database hidden, so only what the test seeds afterwards can be doubtful.
 */
export async function aislar(c: pg.PoolClient): Promise<void> {
  await c.query("delete from public.lotes_de_etiquetas")
  await c.query("update public.afirmaciones set excluida = true where not excluida")
}

export interface Base {
  material: string
  autor: string
}

export async function base(c: pg.PoolClient): Promise<Base> {
  const sufijo = randomUUID().slice(0, 8)
  const autor = await uno(c, "insert into public.autores (nombre, tipo) values ($1, 'persona') returning id", [
    `Autora lote ${sufijo}`,
  ])
  const material = await uno(
    c,
    `insert into public.materiales (titulo, tipo, autor_id, rol, texto_pegado, declaracion_sin_pacientes_en, subido_por, estado)
     values ($1, 'documento', $2, 'referente', 'texto', now(), $3, 'listo') returning id`,
    [`Material lote ${sufijo}`, autor, CONI],
  )
  return { material, autor }
}

interface Idea {
  /** Minutes after a fixed day: the batch takes the oldest claim first. */
  minutos?: number
  tipo?: string
  evidencia?: string
  antigua?: boolean
  excluida?: boolean
}

export function idea(c: pg.PoolClient, b: Base, extra: Idea = {}): Promise<string> {
  return uno(
    c,
    `insert into public.afirmaciones
       (material_id, autor_id, tramo, ubicacion, texto, cita, tipo, evidencia, etiquetas_antiguas, excluida, creada_en)
     values ($1, $2, 0, '{"pagina":1}'::jsonb, 'Una idea', 'cita', $3, $4, $5, $6,
             timestamptz '2026-11-01 12:00:00+00' + $7 * interval '1 minute')
     returning id`,
    [
      b.material,
      b.autor,
      extra.tipo ?? "consejo",
      extra.evidencia ?? "estudio",
      extra.antigua ?? false,
      extra.excluida ?? false,
      extra.minutos ?? 0,
    ],
  )
}

interface Marca {
  marca: string
  red: string
  valor: string
  certeza?: string
  origen?: string
  porQue?: string | null
}

export function marca(c: pg.PoolClient, afirmacion: string, m: Marca): Promise<string> {
  return uno(
    c,
    `insert into public.afirmacion_marcas (afirmacion_id, marca, red, valor, certeza, por_que, origen)
     values ($1, $2, $3, $4, $5, $6, $7) returning id`,
    [afirmacion, m.marca, m.red, m.valor, m.certeza ?? "media", m.porQue ?? null, m.origen ?? "extraccion"],
  )
}

export async function gancho(c: pg.PoolClient, afirmacion: string, certeza: string, origen = "extraccion") {
  await c.query(
    `insert into public.ganchos (afirmacion_id, frase_exacta, frase_sin_gancho, tipo, certeza, version_id, origen)
     select $1, 'Nadie te lo dijo.', 'Hay algo que no se dice.', 'verdad_incomoda', $2, id, $3
       from public.versiones_de_vocabulario where lista = 'gancho' and estado = 'vigente'`,
    [afirmacion, certeza, origen],
  )
}

export async function lote(c: pg.PoolClient): Promise<FilaDeLote[]> {
  return (await c.query<FilaDeLote>(LOTE)).rows
}
```

```ts
              values ($1, $2, $3, $4, $5, $6, $7)`

/** As postgres: last week's batch with one item, a tipo still sin_clasificar. */
async function sembrar(c: pg.PoolClient): Promise<{ lote: string; afirmacion: string }> {
  await aislar(c)
  const b = await base(c)
  const afirmacion = await idea(c, b, { tipo: "sin_clasificar" })
  const lote = await uno(c, `insert into public.lotes_de_etiquetas (semana) values (${SEMANA} - 7) returning id`)
  await c.query(ITEM, [lote, 1, afirmacion, "tipo", "todas", null, "sin_clasificar"])
  return { lote, afirmacion }
}

describe("lotes_de_etiquetas and lote_de_etiquetas_items", () => {
  it("let Coni and WAV read a batch, and nobody else", async () => {
    await como(comoPostgres, async (c) => {
      const e = await sembrar(c)
      const filas = async () => [
        (await c.query("select id from public.lotes_de_etiquetas where id = $1", [e.lote])).rowCount,
        (await c.query("select posicion from public.lote_de_etiquetas_items where lote_id = $1", [e.lote])).rowCount,
      ]
      await asumir(c, comoConi)
      expect(await filas()).toEqual([1, 1])
      await asumir(c, comoMantenedor)
      expect(await filas()).toEqual([1, 1])
      await asumir(c, comoOtra)
      expect(await filas()).toEqual([0, 0])
    })
  })

  it("take no direct write from a session, not even Coni's, and keep the helpers private", async () => {
    await como(comoPostgres, async (c) => {
      const e = await sembrar(c)
      await asumir(c, comoConi)
      const nuevo = await fallaCon(c, `insert into public.lotes_de_etiquetas (semana) values (${SEMANA} - 21)`)
      expect(nuevo.code).toBe("42501")
      const item = await fallaCon(c, ITEM, [e.lote, 2, e.afirmacion, "evidencia", "todas", null, "sin_clasificar"])
      expect(item.code).toBe("42501")
      const borrar = await fallaCon(c, "delete from public.lotes_de_etiquetas where id = $1", [e.lote])
      expect(borrar.code).toBe("42501")
      expect((await fallaCon(c, "select * from public.etiquetas_dudosas()")).code).toBe("42501")
      const llenar = await fallaCon(c, `select public.llenar_lote_de_etiquetas($1::uuid, ${SEMANA})`, [e.lote])
      expect(llenar.code).toBe("42501")
    })
  })

  it("refuses a sixth position and a second item of the same claim in one batch", async () => {
    await como(comoPostgres, async (c) => {
      const e = await sembrar(c)
      const b = await base(c)
      const otra = await idea(c, b, { evidencia: "sin_clasificar" })
      expect((await fallaCon(c, ITEM, [e.lote, 6, otra, "evidencia", "todas", null, "sin_clasificar"])).code).toBe(
        "23514",
      )
      expect(
        (await fallaCon(c, ITEM, [e.lote, 2, e.afirmacion, "evidencia", "todas", null, "sin_clasificar"])).code,
      ).toBe("23505")
    })
  })

  it("loses an item with its claim, and keeps a removed mark's item with no mark", async () => {
    await como(comoPostgres, async (c) => {
      const e = await sembrar(c)
      const b = await base(c)
      const conMarca = await idea(c, b)
      const emocion = await marca(c, conMarca, {
        marca: "emocion",
        red: "linkedin",
        valor: "escepticismo",
        certeza: "baja",
      })
      await c.query(ITEM, [e.lote, 2, conMarca, "emocion", "linkedin", emocion, "certeza_baja"])
      await c.query("delete from public.afirmacion_marcas where id = $1", [emocion])
      const quedan = await c.query<{ posicion: number; marca_id: string | null }>(
        "select posicion, marca_id from public.lote_de_etiquetas_items where lote_id = $1 order by posicion",
        [e.lote],
      )
      expect(quedan.rows).toEqual([
        { posicion: 1, marca_id: null },
        { posicion: 2, marca_id: null },
      ])
      await c.query("delete from public.afirmaciones where id = $1", [e.afirmacion])
      const despues = await c.query("select posicion from public.lote_de_etiquetas_items where lote_id = $1", [e.lote])
      expect(despues.rows).toEqual([{ posicion: 2 }])
    })
  })
})

describe("marca_id in correcciones_de_etiqueta", () => {
```

```ts
import type pg from "pg"
import { afterAll, describe, expect, it } from "vitest"
import { asumir, como, comoConi, comoMantenedor, comoOtra, comoPostgres, fallaCon, pool } from "./db"
import { aislar, base, gancho, idea, LOTE, lote, marca, SEMANA, uno } from "./lote-de-etiquetas-comun"

afterAll(() => pool.end())

/** As postgres: how many batches this week has. */
async function lotesDeLaSemana(c: pg.PoolClient): Promise<number> {
  await asumir(c, comoPostgres)
  const { rows } = await c.query<{ n: number }>(
    `select count(*)::int as n from public.lotes_de_etiquetas where semana = ${SEMANA}`,

  return rows[0]?.n ?? -1
}

describe("lote_de_la_semana", () => {
```

```sql
  m public.afirmacion_marcas;
  g public.ganchos;

  v_version integer;

  v_frase text := nullif(btrim(p_frase), '');

      v_por_que := null;

        raise exception using errcode = '22023', message = 'falta_por_que';
      end if;
      if v_valor not in ('otro', 'otra') then
        v_por_que := null;
      end if;

    if m.id is null then
      insert into public.afirmacion_marcas (afirmacion_id, marca, red, valor, frase, certeza, por_que, version_id, origen)
      values (a.id, p_campo, p_red, v_valor, v_frase, 'alta', v_por_que, v_version, 'coni')
      returning id into v_marca_id;
      v_accion := 'agrega';

          then 'confirma'
        else 'corrige'

-- The doubtful tags (spec 6c-2): only visible claims, never anything of Coni's. tipo or evidencia in sin_clasificar on
-- any claim; on new claims a mark in sin_clasificar, otro or otra, or of low certainty; a hook not confirmed with high
-- certainty. A per-network mark stored with red `todas` is left out: 6c-1 neither shows nor accepts it.
create or replace function public.etiquetas_dudosas()
returns table (afirmacion_id uuid, campo text, red text, marca_id uuid, motivo text, creada_en timestamptz)
language sql stable security definer set search_path = '' as $$
  with visibles as (
    select a.id, a.tipo, a.evidencia, a.etiquetas_antiguas, a.creada_en
    from public.afirmaciones a
    join public.materiales_visibles m on m.id = a.material_id
    where not a.excluida
  )
  select v.id, 'tipo'::text, 'todas'::text, null::uuid, 'sin_clasificar'::text, v.creada_en
  from visibles v where v.tipo = 'sin_clasificar'
  union all
  select v.id, 'evidencia', 'todas', null, 'sin_clasificar', v.creada_en
  from visibles v where v.evidencia = 'sin_clasificar'
  union all
  select v.id, mk.marca, mk.red, mk.id,
         case when mk.valor = 'sin_clasificar' then 'sin_clasificar'
              when mk.valor in ('otro', 'otra') then 'otro'
              else 'certeza_baja' end,
         v.creada_en
  from visibles v
  join public.afirmacion_marcas mk on mk.afirmacion_id = v.id
  where not v.etiquetas_antiguas
    and mk.origen <> 'coni'
    and (mk.marca in ('dato', 'caso')) = (mk.red = 'todas')
    and (mk.valor in ('sin_clasificar', 'otro', 'otra') or mk.certeza = 'baja')
  union all
  select v.id, 'tipo_de_gancho', 'todas', null, 'gancho', v.creada_en
  from visibles v
  join public.ganchos g on g.afirmacion_id = v.id

-- Fills a new batch: (1) what the most recent previous batch left still doubtful, in its old order; (2) the rest by
-- motivo; (3) the oldest claim first, then its id. One item per claim (inside a claim: the order of the fields), five
-- at most.
create or replace function public.llenar_lote_de_etiquetas(p_lote uuid, p_semana date) returns void
language sql security definer set search_path = '' as $$
  with dudosas as (
    select * from public.etiquetas_dudosas()
  ),
  anterior as (
    select i.posicion, i.afirmacion_id, i.campo, i.red, i.marca_id
    from public.lote_de_etiquetas_items i
    where i.lote_id = (
      select l.id from public.lotes_de_etiquetas l where l.semana < p_semana order by l.semana desc limit 1
    )
  ),
  candidatos as (
    select 0 as prioridad, a.posicion::integer as orden, d.creada_en,
           d.afirmacion_id, d.campo, d.red, d.marca_id, d.motivo
    from anterior a
    join dudosas d on d.afirmacion_id = a.afirmacion_id and d.campo = a.campo and d.red = a.red
      and d.marca_id is not distinct from a.marca_id
    union all
    select 1, array_position(array['sin_clasificar', 'otro', 'gancho', 'certeza_baja'], d.motivo), d.creada_en,
           d.afirmacion_id, d.campo, d.red, d.marca_id, d.motivo
    from dudosas d
  ),
  uno_por_afirmacion as (
    select distinct on (c.afirmacion_id) c.*
    from candidatos c
    order by c.afirmacion_id, c.prioridad, c.orden,
      array_position(
        array['tipo', 'evidencia', 'problema', 'solucion', 'emocion', 'publico', 'dato', 'caso', 'tipo_de_gancho'],
        c.campo
      ),
      c.red, c.marca_id
  ),
  elegidos as (
    select u.* from uno_por_afirmacion u
    order by u.prioridad, u.orden, u.creada_en, u.afirmacion_id
    limit 5
  )
  insert into public.lote_de_etiquetas_items (lote_id, posicion, afirmacion_id, campo, red, marca_id, motivo)
  select p_lote, (row_number() over (order by e.prioridad, e.orden, e.creada_en, e.afirmacion_id))::smallint,
         e.afirmacion_id, e.campo, e.red, e.marca_id, e.motivo
  from elegidos e
$$;

-- The week's batch with each item's state. Coni's first read of the week builds it; WAV only reads it (empty when it
-- does not exist yet); anyone else is refused. A batch built with nothing doubtful stays empty all week.
create or replace function public.lote_de_la_semana()
returns table (posicion smallint, afirmacion_id uuid, campo text, red text, marca_id uuid, motivo text, hecha boolean)
language plpgsql security definer set search_path = '' as $$
#variable_conflict use_column
declare
  v_semana date := date_trunc('week', now() at time zone 'America/Santiago')::date;
  v_lote uuid;
begin
  if public.es_coni() then
    -- Two tabs on Monday: the second waits on the first one's row, inserts nothing, and reads what the first built.
    insert into public.lotes_de_etiquetas (semana) values (v_semana)
    on conflict (semana) do nothing
    returning id into v_lote;
    if v_lote is not null then
      perform public.llenar_lote_de_etiquetas(v_lote, v_semana);
    end if;
  elsif not public.es_mantenedor() then
    raise exception using errcode = '42501', message = 'solo_coni';
  end if;

  -- Done: the tag is no longer doubtful. Nothing is written to mark it, so a correction from the claim's page counts.
  return query
  with dudosas as (select * from public.etiquetas_dudosas())
  select i.posicion, i.afirmacion_id, i.campo, i.red, i.marca_id, i.motivo,
         not exists (
           select 1 from dudosas d
           where d.afirmacion_id = i.afirmacion_id and d.campo = i.campo and d.red = i.red
             and d.marca_id is not distinct from i.marca_id
         )
  from public.lote_de_etiquetas_items i
  join public.lotes_de_etiquetas l on l.id = i.lote_id
  where l.semana = v_semana
  order by i.posicion;
end
$$;

-- The helpers run only inside lote_de_la_semana (as its owner); sessions call lote_de_la_semana and nothing else.
revoke execute on function
  public.etiquetas_dudosas(),
  public.llenar_lote_de_etiquetas(uuid, date)
from public, anon, authenticated;
revoke execute on function public.lote_de_la_semana() from public, anon;
grant execute on function public.lote_de_la_semana() to authenticated;
```

```ts
  red: RedDeEtiqueta
  accion: Accion
```

```ts
/**
 * What the latest of her actions on that tag says; a removal says nothing (the row is gone). A log row with a mark's
 * row counts only for that mark; one without (tipo, evidencia, the hook, rows from before 6c-2) by field and network.
 */
export function revisionDe(
  correcciones: readonly CorreccionLeida[],
  campo: CampoDeEtiqueta,
  red: RedDeEtiqueta,
  marcaId: string | null = null,
): string | null {
  const ultima = correcciones
    .filter(
      (c) =>
        c.campo === campo && c.red === red && c.accion !== "quita" && (c.marcaId === null || c.marcaId === marcaId),
    )
    .reduce<CorreccionLeida | null>(
      (masNueva, c) => (masNueva === null || Date.parse(c.creadaEn) > Date.parse(masNueva.creadaEn) ? c : masNueva),
      null,
    )
  if (ultima === null) return null
  return ultima.accion === "confirma" ? CONFIRMADA_POR_TI : CORREGIDA_POR_TI
}
```

```ts
export function volverDesde(
  consulta: Record<string, string | string[] | undefined>,
  materialId: string,

  const pedido = Array.isArray(consulta.desde) ? consulta.desde[0] : consulta.desde
```

```ts
  switch (motivo) {

      return "Claude no estaba segura"
    case "otro":

    case "sin_clasificar":

interface Actual {
  valor: string
  frase: string | null
  porQue: string | null
  certezaBaja: boolean
}

/** What the tag says now on the claim; null when its mark or hook is gone. */
function actualDe(item: ItemDeLote, afirmacion: AfirmacionLeida): Actual | null {
  if (esMarca(item.campo)) {
    const marca = item.marcaId ? afirmacion.marcas.find((m) => m.id === item.marcaId) : undefined
    return marca
      ? { valor: marca.valor, frase: marca.frase, porQue: marca.porQue, certezaBaja: marca.certeza === "baja" }
      : null
  }
  if (item.campo === "tipo_de_gancho") {
    const gancho = afirmacion.gancho
    return gancho
      ? { valor: gancho.tipo, frase: gancho.fraseExacta, porQue: null, certezaBaja: gancho.certeza === "baja" }
      : null
  }
  const valor = item.campo === "tipo" ? afirmacion.tipo : afirmacion.evidencia
  return { valor, frase: null, porQue: null, certezaBaja: false }
}

/** One card of the batch (spec 6c-2); null when there is nothing to show (claim gone, pending mark gone). */
export function tarjetaDeItem(
  item: ItemDeLote,
  afirmacion: AfirmacionLeida | null,
  catalogo: CatalogoDeEtiquetas,
): TarjetaDeEtiqueta | null {
  if (afirmacion === null) return null
  const actual = actualDe(item, afirmacion)
  const comun: Comun = {
    posicion: item.posicion,
    afirmacionId: afirmacion.id,
    texto: afirmacion.texto,
    autor: afirmacion.autor?.nombre ?? null,
    titulo: tituloDeEtiqueta(item.campo, item.red),
    frase: actual?.frase ?? null,
    href: hrefDeAfirmacion(afirmacion.id, RUTA_DE_REVISION_DE_ETIQUETAS),
  }
  if (item.hecha) {
    if (actual === null) return { ...comun, estado: "hecha", etiqueta: null, revision: TEXTOS_DE_REVISION.yaNoEsta }
    return {
      ...comun,
      estado: "hecha",
      etiqueta: etiquetaDe(catalogo, item.campo, item.red, actual.valor),
      revision:
        revisionDe(afirmacion.correcciones, item.campo, item.red, item.marcaId) ?? TEXTOS_DE_REVISION.yaNoEstaPendiente,
    }
  }
  if (actual === null) return null
  const opciones = opcionesDe(catalogo, item.campo, item.red)
  return {
    ...comun,
    estado: "pendiente",
    campo: item.campo,
    red: item.red,
    marcaId: item.marcaId,
    valor: actual.valor,
    etiqueta: etiquetaDe(catalogo, item.campo, item.red, actual.valor),
    porQue: actual.porQue,
    certezaBaja: actual.certezaBaja,
    motivo: porQueEstaAqui(item.motivo, actual.porQue),
    opciones,
    conFrase: esMarca(item.campo),
    confirmable:
      opciones.length === 0 || opciones.some((grupo) => grupo.opciones.some((o) => o.valor === actual.valor)),
  }
}
```

```ts
import { z } from "zod"
import { type AfirmacionLeida, CAMPOS } from "@/lib/dominio/biblioteca/etiquetas-de-afirmacion"

import { leerCatalogoDeEtiquetas } from "./vocabulario"

type Db = SupabaseClient<Database>

// Checked once here: the generated types say text where the table's checks say a closed set.
const FilaDeLote = z.object({
  posicion: z.number().int(),
  afirmacion_id: z.string(),
  campo: z.enum(CAMPOS),
  red: z.enum(["linkedin", "instagram", "todas"]),
  marca_id: z.string().nullable(),
  motivo: z.enum(MOTIVOS_DE_DUDA),
  hecha: z.boolean(),
})

/** The week's batch (spec 6c-2), in order. Coni's first read of the week builds it. */
export async function leerLoteDeLaSemana(db: Db): Promise<ItemDeLote[]> {
  const { data, error } = await db.rpc("lote_de_la_semana")
  if (error) throw new Error(`No pude leer el lote de etiquetas de la semana: ${error.message}`, { cause: error })
  return z
    .array(FilaDeLote)
    .parse(data)
    .map((fila) => ({
      posicion: fila.posicion,
      afirmacionId: fila.afirmacion_id,
      campo: fila.campo,
      red: fila.red,
      marcaId: fila.marca_id,
      motivo: fila.motivo,
      hecha: fila.hecha,
    }))
}

/** Inicio opens even when this read fails (as the merges line): the failure is logged and counts 0. */
export async function contarEtiquetasParaInicio(db: Db): Promise<number> {
  try {
    return pendientesDeLote(await leerLoteDeLaSemana(db))
  } catch (error) {
    console.error("No pude contar las etiquetas para revisar para Inicio", error)
    return 0
  }
}

export type RevisionDeEtiquetas =
  | { estado: "lista"; items: ItemDeLote[]; tarjetas: TarjetaDeEtiqueta[] }
  | { estado: "error" }

/** The batch with one card per item; a failure is logged and the page says it in her words. */
export async function leerRevisionDeEtiquetas(db: Db): Promise<RevisionDeEtiquetas> {
  try {
    const items = await leerLoteDeLaSemana(db)
    if (items.length === 0) return { estado: "lista", items, tarjetas: [] }
    const ids = [...new Set(items.map((item) => item.afirmacionId))]
    const [afirmaciones, catalogo] = await Promise.all([
      Promise.all(ids.map((id) => leerAfirmacion(db, id))),
      leerCatalogoDeEtiquetas(db),
    ])
    const porId = new Map<string, AfirmacionLeida>(
      afirmaciones.flatMap((afirmacion) => (afirmacion ? [[afirmacion.id, afirmacion] as const] : [])),
    )
    const tarjetas = items.flatMap((item) => {
      const tarjeta = tarjetaDeItem(item, porId.get(item.afirmacionId) ?? null, catalogo)
      return tarjeta ? [tarjeta] : []
    })
    return { estado: "lista", items, tarjetas }
  } catch (error) {
    console.error("No pude cargar las etiquetas para revisar", error)
```

```ts
/**
 * No doubtful tag and no batch (spec 6c-2): Inicio builds the week's batch on every visit, so a spec that leaves one
 * would add a line to a later spec's Inicio. `salvo` keeps one claim's marks.
 */
export async function sinEtiquetasDudosas(opciones: { salvo?: string } = {}): Promise<void> {
  await pool.query("delete from public.lotes_de_etiquetas")
  await pool.query("update public.afirmaciones set tipo = 'consejo' where tipo = 'sin_clasificar'")
  await pool.query("update public.afirmaciones set evidencia = 'estudio' where evidencia = 'sin_clasificar'")
  await pool.query("update public.ganchos set certeza = 'alta' where certeza <> 'alta'")
  await pool.query(
    `delete from public.afirmacion_marcas
      where afirmacion_id is distinct from $1::uuid and origen <> 'coni'
        and (certeza = 'baja' or valor in ('otro', 'otra', 'sin_clasificar'))`,
    [opciones.salvo ?? null],
  )
}

/**
 * The week's batch of three, built on the first visit: (1) IDEA_DE_CONI's tipo in sin_clasificar (an old claim: only
 * «Cambiar»), (2) GANCHO_INSTAGRAM's hook type of medium certainty, (3) GANCHO_LINKEDIN's LinkedIn emotion of low
 * certainty (Escepticismo).
 */
export async function sembrarLoteDeEtiquetas(): Promise<EscenaDeEtiquetas> {
  const escena = await sembrarEtiquetas()
  await sinEtiquetasDudosas({ salvo: escena.nueva })
  await pool.query("update public.ganchos set certeza = 'media' where afirmacion_id = $1", [escena.instagram])
  await pool.query("update public.afirmaciones set tipo = 'sin_clasificar' where id = $1", [escena.antigua])
  return escena
}
```
