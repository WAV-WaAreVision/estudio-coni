# Change 6c-1 · See and correct a claim's tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page per claim, `/biblioteca/afirmaciones/[id]`, where Coni sees every tag of a claim (tipo, evidencia, the
marks per network, dato and caso, the hook type) and confirms, corrects, adds or removes them, every change written to
an append-only log; author, topic and material lists show short badges that open it, and the 6b hook panel and page
link to it.

**Architecture:** One migration adds `correcciones_de_etiqueta` (read by Coni and WAV, written by nobody directly) and
three `security definer` functions (`corregir_etiqueta`, `confirmar_etiqueta`, `quitar_marca`) that check the
vigente lists, change `afirmaciones` / `afirmacion_marcas` / `ganchos` and log in the same transaction. A pure domain
module (`etiquetas-de-afirmacion.ts`) owns labels (from the vocabulary), options, grouping, old/new detection, badge
choice and the way back, so every rule is unit-tested. One reader loads a claim with its marks, hook and log; Server
Actions call the functions and turn their refusals into Coni's words. The page is a Server Component with one client
editor per tag.

**Tech Stack:** Next.js 16 App Router (Server Components + Server Actions), Supabase Postgres (RLS, `security definer`
plpgsql), Zod, Tailwind v4 tokens, Vitest (unit with jsdom, integration against local Supabase), Playwright.

Spec: `docs/superpowers/specs/2026-11-26-etiquetas-6c1-design.md` (authoritative, approved by Federico).

## Decisions taken while planning (spec gaps)

1. **Which mark row.** `afirmacion_marcas` has no unique key on (claim, mark, network) and the extraction may write two
   `dato` rows. The three functions take the spec's parameters plus a trailing `p_marca_id uuid default null`. With an
   id, that row is used (it must belong to the claim, mark and network, else `P0002 sin_marca`). Without one: zero rows
   means `agrega` in `corregir_etiqueta` and `P0002 sin_marca` in the other two; more than one is `22023 marca_ambigua`.
   The screen always sends the id of an existing row.
2. **Error codes added** (the spec's are kept exactly: `42501 solo_coni_corrige`, `22023 afirmacion_antigua`,
   `P0002 sin_gancho`, `22023 campo_desconocido`, `22023 valor_fuera_de_lista`): `P0002 afirmacion_inexistente`
   (missing, hidden or deleted-material claim), `22023 red_invalida` (per-network marks need linkedin or instagram;
   tipo, evidencia, dato, caso and tipo_de_gancho need `todas`), `22023 falta_por_que`, `22023 falta_frase`,
   `P0002 sin_marca`, `22023 marca_ambigua`.
3. **Old or new** (rule changed by Federico on 2026-11-26, after batches A and B). The migration adds
   `afirmaciones.etiquetas_antiguas boolean not null default false` and sets it once to true on the claims that had no
   mark and no `ganchos` row at that moment. Old = that column; everything extracted afterwards is new, even with zero
   marks, so Coni can add marks to it. The functions read the column on the locked row; the earlier rule (marks, or a
   `quita` log row) and its helper `afirmacion_con_marcas` are gone. The code blocks of tasks 2 and 4 below still show
   the earlier rule; the migration and `esAfirmacionNueva` are the source of truth.
4. **The phrase.** For list marks `p_frase` is the new phrase (empty clears it); the editor always sends what its field
   holds, prefilled with the current one. `dato` and `caso` keep their `valor` and only change the phrase (required);
   an added `dato`/`caso` takes `p_valor`, or the phrase when it is empty.
5. **`confirma` from `corregir_etiqueta`**: same value, same phrase and same reason. It still sets `certeza = 'alta'`
   and `origen = 'coni'` on marks and hooks, like `confirmar_etiqueta`.
6. **Confirming a `sin_clasificar` tipo or evidencia** is refused with `valor_fuera_de_lista`: there is no value to
   confirm.
7. **The `quita` row** keeps the removed row's `version_id` (the list its `antes` came from).
8. **No new side panel.** The spec's «side panel on desktop lists that already have one» is read as: the 6b hook
   panel (the only Biblioteca panel that shows a claim) gains «Ver la afirmación». Badges in author, topic and material
   lists link to the page.
9. **The material map has no per-claim rows today**: it gains a folded «Cada idea (n)» that reuses `ListaDeIdeas` with
   badges.
10. **Badge emotion per network**: Coni's own (origen `coni`) first, then the highest certainty, then the oldest.
11. **«Volver»** reads a validated `?desde=` (an author, topic, material or hook page); without one it goes to the
    claim's material.
12. **«Corregida por ti» / «Confirmada por ti»**: from the latest log row of that field and network (`confirma` gives
    the second). On marks it also needs `origen = 'coni'`.
13. **An old claim's free-text hook** (`afirmaciones.gancho`) shows as reference in the marks note; old claims have no
    `ganchos` row, so their hook type is not editable (`sin_gancho`).
14. **A per-network mark stored with `red = 'todas'`** is not shown: the extraction never writes one
    (`marcasNormalizadas` splits it).
15. **`creada_en` defaults to `now()`** as the spec says; tests never rely on the order of two log rows written in
    the same transaction.

```sql
    raise exception using errcode = '22023', message = 'campo_desconocido';
  end if;
  if p_red is null or p_red not in ('linkedin', 'instagram', 'todas')
     or (p_campo in ('problema', 'solucion', 'emocion', 'publico')) <> (p_red in ('linkedin', 'instagram')) then
    raise exception using errcode = '22023', message = 'red_invalida';
  end if;
end
$$;

-- The claim as the Biblioteca shows it (not hidden, its material not deleted with «Deshacer»), locked.
create or replace function public.etiqueta_afirmacion(p_afirmacion uuid) returns public.afirmaciones
language plpgsql set search_path = '' as $$
declare
  a public.afirmaciones;
begin
  select f.* into a
  from public.afirmaciones f
  join public.materiales_visibles m on m.id = f.material_id
  where f.id = p_afirmacion and not f.excluida
  for update of f;
  if a.id is null then
    raise exception using errcode = 'P0002', message = 'afirmacion_inexistente';
  end if;
  return a;
end
$$;

-- The mark row to act on, locked: the one named by id, else the only one of that mark and network. With
-- `p_puede_faltar` a missing row comes back empty (all nulls) for corregir_etiqueta to add it.
create or replace function public.etiqueta_marca(
  p_afirmacion uuid, p_marca text, p_red text, p_marca_id uuid, p_puede_faltar boolean
) returns public.afirmacion_marcas
language plpgsql set search_path = '' as $$
declare
  m public.afirmacion_marcas;
  cuantas integer;
begin
  if p_marca_id is not null then
    select * into m from public.afirmacion_marcas
    where id = p_marca_id and afirmacion_id = p_afirmacion and marca = p_marca and red = p_red
    for update;
    if m.id is null then
      raise exception using errcode = 'P0002', message = 'sin_marca';
    end if;
    return m;
  end if;
  select count(*) into cuantas from public.afirmacion_marcas
  where afirmacion_id = p_afirmacion and marca = p_marca and red = p_red;
  if cuantas > 1 then
    raise exception using errcode = '22023', message = 'marca_ambigua';
  end if;
  select * into m from public.afirmacion_marcas
  where afirmacion_id = p_afirmacion and marca = p_marca and red = p_red
  for update;
  if m.id is null and not p_puede_faltar then
    raise exception using errcode = 'P0002', message = 'sin_marca';
  end if;
  return m;
end
$$;

-- Coni corrects one tag (spec 6c-1). tipo and evidencia on any claim; marks only on a new one, the row updated or
-- added; the hook type on its `ganchos` row. One log row in the same transaction: `corrige`, `agrega`, or `confirma`
-- when nothing changed.
create or replace function public.corregir_etiqueta(
  p_afirmacion uuid, p_campo text, p_red text, p_valor text,
  p_frase text default null, p_por_que text default null, p_marca_id uuid default null
) returns void
language plpgsql security definer set search_path = '' as $$
declare
  a public.afirmaciones;
  m public.afirmacion_marcas;
  g public.ganchos;
  v_lista text := public.etiqueta_lista_de_campo(p_campo);
  v_version integer;
  v_valor text := nullif(btrim(p_valor), '');
  v_frase text := nullif(btrim(p_frase), '');
  v_por_que text := nullif(btrim(p_por_que), '');
  v_antes text;
  v_accion text;
begin
  perform public.etiqueta_exigir(p_campo, p_red);
  a := public.etiqueta_afirmacion(p_afirmacion);

  if p_campo in ('problema', 'solucion', 'emocion', 'publico', 'dato', 'caso') then
    if not public.afirmacion_con_marcas(a.id) then
      raise exception using errcode = '22023', message = 'afirmacion_antigua';
    end if;
    m := public.etiqueta_marca(a.id, p_campo, p_red, p_marca_id, true);
    if p_campo in ('dato', 'caso') then
      -- No list: only the phrase changes. An added one takes the short label sent, or its phrase.
      if v_frase is null then
        raise exception using errcode = '22023', message = 'falta_frase';
      end if;
      v_valor := coalesce(m.valor, v_valor, v_frase);
      v_version := null;
      v_por_que := null;
    else
      v_version := public.etiqueta_version_vigente(v_lista, p_red);
      if v_valor is null or not (
        public.etiqueta_en_lista(v_version, v_valor) or (v_valor = 'otro' and v_lista in ('dolor', 'publico'))
      ) then
        raise exception using errcode = '22023', message = 'valor_fuera_de_lista';
      end if;
      if v_valor in ('otro', 'otra') and v_por_que is null then
        raise exception using errcode = '22023', message = 'falta_por_que';
      end if;
      if v_valor not in ('otro', 'otra') then
        v_por_que := null;
      end if;
    end if;

    if m.id is null then
      insert into public.afirmacion_marcas (afirmacion_id, marca, red, valor, frase, certeza, por_que, version_id, origen)
      values (a.id, p_campo, p_red, v_valor, v_frase, 'alta', v_por_que, v_version, 'coni');
      v_accion := 'agrega';
    else
      v_accion := case
        when m.valor = v_valor and m.frase is not distinct from v_frase and m.por_que is not distinct from v_por_que
          then 'confirma'
        else 'corrige'
      end;
      update public.afirmacion_marcas
      set valor = v_valor, frase = v_frase, por_que = v_por_que, certeza = 'alta', origen = 'coni',
          version_id = v_version
      where id = m.id;
    end if;
    insert into public.correcciones_de_etiqueta
      (afirmacion_id, campo, red, accion, antes, despues, frase_antes, frase_despues, por_que, certeza_antes, version_id)
    values (
      a.id, p_campo, p_red, v_accion, m.valor, v_valor,
      case when m.frase is distinct from v_frase then m.frase end,
      case when m.frase is distinct from v_frase then v_frase end,
      v_por_que, m.certeza, v_version
    );

  elsif p_campo = 'tipo_de_gancho' then
    select * into g from public.ganchos where afirmacion_id = a.id for update;
    if g.id is null then
      raise exception using errcode = 'P0002', message = 'sin_gancho';
    end if;
    v_version := public.etiqueta_version_vigente('gancho', 'todas');
    if v_valor is null or not (v_valor = 'ninguno' or public.etiqueta_en_lista(v_version, v_valor)) then
      raise exception using errcode = '22023', message = 'valor_fuera_de_lista';
    end if;
    v_accion := case when g.tipo = v_valor then 'confirma' else 'corrige' end;
    update public.ganchos set tipo = v_valor, certeza = 'alta', origen = 'coni', version_id = v_version
    where id = g.id;
    insert into public.correcciones_de_etiqueta
      (afirmacion_id, campo, red, accion, antes, despues, certeza_antes, version_id)
    values (a.id, p_campo, p_red, v_accion, g.tipo, v_valor, g.certeza, v_version);

  else
    v_version := public.etiqueta_version_vigente(v_lista, 'todas');
    if v_valor is null or not public.etiqueta_en_lista(v_version, v_valor) then
      raise exception using errcode = '22023', message = 'valor_fuera_de_lista';
    end if;
    v_antes := case when p_campo = 'tipo' then a.tipo else a.evidencia end;
    if p_campo = 'tipo' then
      update public.afirmaciones set tipo = v_valor where id = a.id;
    else
      update public.afirmaciones set evidencia = v_valor where id = a.id;
    end if;
    insert into public.correcciones_de_etiqueta (afirmacion_id, campo, red, accion, antes, despues, version_id)
    values (a.id, p_campo, p_red, case when v_antes = v_valor then 'confirma' else 'corrige' end, v_antes, v_valor,
            v_version);
  end if;
end
$$;

-- «Está bien»: the value stays; a mark or a hook becomes alta and Coni's. Logs `confirma`.
create or replace function public.confirmar_etiqueta(
  p_afirmacion uuid, p_campo text, p_red text, p_marca_id uuid default null
) returns void
language plpgsql security definer set search_path = '' as $$
declare
  a public.afirmaciones;
  m public.afirmacion_marcas;
  g public.ganchos;
  v_antes text;
begin
  perform public.etiqueta_exigir(p_campo, p_red);
  a := public.etiqueta_afirmacion(p_afirmacion);

  if p_campo in ('problema', 'solucion', 'emocion', 'publico', 'dato', 'caso') then
    if not public.afirmacion_con_marcas(a.id) then
      raise exception using errcode = '22023', message = 'afirmacion_antigua';
    end if;
    m := public.etiqueta_marca(a.id, p_campo, p_red, p_marca_id, false);
    update public.afirmacion_marcas set certeza = 'alta', origen = 'coni' where id = m.id;
    insert into public.correcciones_de_etiqueta
      (afirmacion_id, campo, red, accion, antes, despues, por_que, certeza_antes, version_id)
    values (a.id, p_campo, p_red, 'confirma', m.valor, m.valor, m.por_que, m.certeza, m.version_id);

  elsif p_campo = 'tipo_de_gancho' then
    select * into g from public.ganchos where afirmacion_id = a.id for update;
    if g.id is null then
      raise exception using errcode = 'P0002', message = 'sin_gancho';
    end if;
    update public.ganchos set certeza = 'alta', origen = 'coni' where id = g.id;
    insert into public.correcciones_de_etiqueta
      (afirmacion_id, campo, red, accion, antes, despues, certeza_antes, version_id)
    values (a.id, p_campo, p_red, 'confirma', g.tipo, g.tipo, g.certeza, g.version_id);

  else
    v_antes := case when p_campo = 'tipo' then a.tipo else a.evidencia end;
    if v_antes = 'sin_clasificar' then
      raise exception using errcode = '22023', message = 'valor_fuera_de_lista';
    end if;
    insert into public.correcciones_de_etiqueta (afirmacion_id, campo, red, accion, antes, despues, version_id)
    values (a.id, p_campo, p_red, 'confirma', v_antes, v_antes,
            public.etiqueta_version_vigente(p_campo, 'todas'));
  end if;
end
$$;

-- «Quitar»: deletes one mark of a new claim and logs `quita` with what it was.
create or replace function public.quitar_marca(
  p_afirmacion uuid, p_marca text, p_red text, p_marca_id uuid default null
) returns void
language plpgsql security definer set search_path = '' as $$
declare
  a public.afirmaciones;
  m public.afirmacion_marcas;
begin
  perform public.etiqueta_exigir(p_marca, p_red);
  if p_marca not in ('problema', 'solucion', 'emocion', 'publico', 'dato', 'caso') then
    raise exception using errcode = '22023', message = 'campo_desconocido';
  end if;
  a := public.etiqueta_afirmacion(p_afirmacion);
  if not public.afirmacion_con_marcas(a.id) then
    raise exception using errcode = '22023', message = 'afirmacion_antigua';
  end if;
  m := public.etiqueta_marca(a.id, p_marca, p_red, p_marca_id, false);
  delete from public.afirmacion_marcas where id = m.id;
  insert into public.correcciones_de_etiqueta
    (afirmacion_id, campo, red, accion, antes, despues, frase_antes, certeza_antes, version_id)
  values (a.id, p_marca, p_red, 'quita', m.valor, null, m.frase, m.certeza, m.version_id);
end
$$;
```

```ts
function valoresDe(catalogo: CatalogoDeEtiquetas, campo: CampoDeEtiqueta, red: RedDeEtiqueta): ValorDeCatalogo[] {
  const deRed = (porRed: Record<Red, ValorDeCatalogo[]>) => (red === "instagram" ? porRed.instagram : porRed.linkedin)
  switch (campo) {
    case "tipo":
      return catalogo.tipo
    case "evidencia":
      return catalogo.evidencia
    case "emocion":

    case "tipo_de_gancho":
      return catalogo.gancho

    case "solucion":

    case "publico":

  }

export function etiquetaDe(

  red: RedDeEtiqueta,
  valor: string,

// Coni's four emotion groups (emociones.md); the vocabulary has the group of each value, not a title.
const GRUPOS_DE_EMOCION = [
  ["problema", "Problema"],
  ["puente", "Puente"],
  ["solucion", "Solución"],
  ["respaldo", "Respaldo"],
] as const

function comoOpcion(v: ValorDeCatalogo): OpcionDeEtiqueta {
  const partes = [v.activacion ? `Activación ${v.activacion}.` : null, v.descripcion ?? null].filter(
    (parte): parte is string => parte !== null,
  )
  return { valor: v.valor, etiqueta: v.etiqueta, detalle: partes.length > 0 ? partes.join(" ") : null }
}

/** What she can choose: the active values (retired ones never), emotions by group, plus the fallbacks the field takes. */
export function opcionesDe(
  catalogo: CatalogoDeEtiquetas,
  campo: CampoDeEtiqueta,
  red: RedDeEtiqueta,
): GrupoDeOpciones[] {
  const activos = valoresDe(catalogo, campo, red).filter((v) => v.activo)
  if (campo === "dato" || campo === "caso") return []
  if (campo === "emocion")
    return GRUPOS_DE_EMOCION.flatMap(([grupo, titulo]) => {
      const opciones = activos.filter((v) => v.grupo === grupo).map(comoOpcion)
      return opciones.length > 0 ? [{ titulo, opciones }] : []
    })
  const opciones = activos.map(comoOpcion)
  if (campo === "problema" || campo === "solucion" || campo === "publico")
    opciones.push({ valor: "otro", etiqueta: ETIQUETA_OTRO, detalle: "Cuando nada calza. Pide una línea de por qué." })
  if (campo === "tipo_de_gancho") opciones.push({ valor: "ninguno", etiqueta: ETIQUETA_NINGUNO, detalle: null })
  return [{ titulo: null, opciones }]
}
```

```ts
  const grupos: MarcasAgrupadas = { linkedin: sinMarcas(), instagram: sinMarcas(), dato: [], caso: [] }
  for (const marca of marcas) {
    if (marca.marca === "dato" || marca.marca === "caso") grupos[marca.marca].push(marca)
    // The extraction splits a per-network mark in one per network (marcasNormalizadas): a `todas` row has no place.
    else if (marca.red !== "todas") grupos[marca.red][marca.marca].push(marca)
  }
  return grupos
}

export const CORREGIDA_POR_TI = "Corregida por ti"
export const CONFIRMADA_POR_TI = "Confirmada por ti"

/** What the latest of her actions on that field and network says; a removal says nothing (the row is gone). */
export function revisionDe(
  correcciones: readonly CorreccionLeida[],
  campo: CampoDeEtiqueta,
  red: RedDeEtiqueta,
): string | null {
  const ultima = correcciones
    .filter((c) => c.campo === campo && c.red === red && c.accion !== "quita")
    .reduce<CorreccionLeida | null>(
      (masNueva, c) => (masNueva === null || Date.parse(c.creadaEn) > Date.parse(masNueva.creadaEn) ? c : masNueva),
      null,
    )
  if (ultima === null) return null
  return ultima.accion === "confirma" ? CONFIRMADA_POR_TI : CORREGIDA_POR_TI
}

const RANGO_DE_CERTEZA: Record<Certeza, number> = { alta: 0, media: 1, baja: 2 }

/** Per network, Coni's own emotion first, then the most certain, then the oldest (plan decision 10). */
export function insigniasDeIdea(
  idea: { tipo: string; evidencia: string },
  emociones: readonly EmocionDeIdea[],
  catalogo: CatalogoDeEtiquetas,
): Insignias {
  return {
    tipo: etiquetaDe(catalogo, "tipo", "todas", idea.tipo),
    evidencia: etiquetaDe(catalogo, "evidencia", "todas", idea.evidencia),
    emociones: REDES.flatMap((red) => {
      const elegida = emociones
        .filter((emocion) => emocion.red === red)
        .toSorted(
          (a, b) =>
            Number(b.origen === "coni") - Number(a.origen === "coni") ||
            RANGO_DE_CERTEZA[a.certeza] - RANGO_DE_CERTEZA[b.certeza],
        )[0]
      return elegida ? [{ red, etiqueta: etiquetaDe(catalogo, "emocion", red, elegida.valor) }] : []
    }),
  }
}

export function insigniasPorIdea(
  ideas: readonly { id: string; tipo: string; evidencia: string }[],
  emociones: readonly EmocionDeIdea[],
  catalogo: CatalogoDeEtiquetas,

    ideas.map((idea) => [
      idea.id,
      insigniasDeIdea(
        idea,
        emociones.filter((emocion) => emocion.afirmacionId === idea.id),
        catalogo,
      ),
    ]),
  )
}
```

```ts
  certeza: z.enum(CERTEZAS),
  origen: ORIGEN,
})

// A hundred ideas per request keeps the `in (...)` address short; each has at most a few emotions.
const IDEAS_POR_PEDIDO = 100

async function leerEmociones(db: Db, ids: readonly string[]): Promise<EmocionDeIdea[]> {
  const lotes: string[][] = []
  for (let desde = 0; desde < ids.length; desde += IDEAS_POR_PEDIDO) lotes.push(ids.slice(desde, desde + IDEAS_POR_PEDIDO))
  const respuestas = await Promise.all(
    lotes.map((lote) =>
      db
        .from("afirmacion_marcas")
        .select("afirmacion_id, red, valor, certeza, origen")
        .eq("marca", "emocion")
        .in("afirmacion_id", lote)
        .order("creada_en")
        .order("id"),
    ),
  )
  return respuestas.flatMap(({ data, error }) => {
    if (error) throw new Error(`No pude leer las emociones de las ideas: ${error.message}`, { cause: error })
    return z
      .array(FilaDeEmocion)
      .parse(data)
      .map((fila) => ({
        afirmacionId: fila.afirmacion_id,
        red: fila.red,
        valor: fila.valor,
        certeza: fila.certeza,
        origen: fila.origen,
      }))
  })
}

/** The badges of the ideas a list shows (spec 6c-1), by idea id. */
export async function leerInsigniasDeIdeas(db: Db, ideas: readonly IdeaLeida[]): Promise<Map<string, Insignias>> {
  if (ideas.length === 0) return new Map()
  const [catalogo, emociones] = await Promise.all([
    leerCatalogoDeEtiquetas(db),
    leerEmociones(
      db,
      ideas.map((idea) => idea.id),
    ),
  ])
  return insigniasPorIdea(ideas, emociones, catalogo)
}
```

```tsx
"use client"

import { useId, useState } from "react"
import { Boton } from "@/components/ui/boton"
import { ConfirmacionEnLinea } from "@/components/ui/confirmacion-en-linea"
import { Eleccion } from "@/components/ui/filas"
import { LineaDeError } from "@/components/ui/linea-de-error"
import { useAccion } from "@/components/use-accion"
import {
  type CampoDeEtiqueta,
  CERTEZA_BAJA,
  ELIGE_UN_VALOR,
  esMarca,
  FALTA_FRASE,
  FALTA_POR_QUE,
  type GrupoDeOpciones,
  pidePorQue,
  type RedDeEtiqueta,
} from "@/lib/dominio/biblioteca/etiquetas-de-afirmacion"
import { confirmarEtiquetaAccion, corregirEtiquetaAccion, quitarMarcaAccion } from "../../acciones"
import { CLASES_DE_CAMPO } from "../../campo"

/** What a tag says now, already in her words. */
export interface EtiquetaActual {
  valor: string
  etiqueta: string
  frase: string | null
  porQue: string | null
  certezaBaja: boolean
  /** «Corregida por ti» or «Confirmada por ti», when she already acted on it. */
  revision: string | null
}

interface Propiedades {
  afirmacionId: string
  campo: CampoDeEtiqueta
  red: RedDeEtiqueta
  /** The mark's row; null for tipo, evidencia, the hook, and a mark to add. */
  marcaId: string | null
  /** «Emoción en Instagram»: names the tag, its list and its «Agregar». */
  titulo: string
  /** Null: the mark is missing and the tag offers «Agregar». */
  actual: EtiquetaActual | null
  /** Empty for dato and caso: only their phrase changes. */
  opciones: readonly GrupoDeOpciones[]
  conFrase: boolean
  quitable: boolean
}

/**
 * One tag (spec 6c-1): tapping it opens its list with «Está bien» and «Cambiar»; «Otro» or «Otra» asks one line of why;
 * a mark can be removed after a confirmation. A missing mark offers «Agregar». The refreshed page brings the new value.
 */
export function EditorDeEtiqueta({
  afirmacionId,
  campo,
  red,
  marcaId,
  titulo,
  actual,
  opciones,
  conFrase,
  quitable,
}: Propiedades) {
  const id = useId()
  const [abierto, setAbierto] = useState(false)
  const [elegido, setElegido] = useState(actual?.valor ?? "")
  const [frase, setFrase] = useState(actual?.frase ?? "")
  const [porQue, setPorQue] = useState(actual?.porQue ?? "")
  const [quitando, setQuitando] = useState(false)
  const [aviso, setAviso] = useState<string | null>(null)
  const { pendiente, error, ejecutar, limpiarError } = useAccion()
  const conLista = opciones.length > 0
  const panel = `${id}-panel`

  function cerrar() {
    setAbierto(false)
    setQuitando(false)
    setAviso(null)
    limpiarError()
  }

  function guardar() {
    setAviso(null)
    if (conLista && elegido === "") {
      setAviso(ELIGE_UN_VALOR)
      return
    }
    if (!conLista && frase.trim() === "") {
      setAviso(FALTA_FRASE)
      return
    }
    if (pidePorQue(elegido) && porQue.trim() === "") {
      setAviso(FALTA_POR_QUE)
      return
    }
    ejecutar(
      () =>
        corregirEtiquetaAccion({
          afirmacionId,
          campo,
          red,
          marcaId,
          valor: elegido,
          frase,
          porQue: pidePorQue(elegido) ? porQue : "",
        }),
      cerrar,
    )
  }

  const problema = aviso ?? (quitando ? null : error)
  // Only a mark has a row to remove; tipo, evidencia and the hook never offer «Quitar».
  const marca = esMarca(campo) ? campo : null

  return (
    <div className="grid gap-2 rounded-panel bg-piedra-alta p-3">
      {actual ? (
        <button
          type="button"
          aria-expanded={abierto}
          aria-controls={panel}
          onClick={() => (abierto ? cerrar() : setAbierto(true))}
          className="grid min-h-objetivo w-full gap-0.5 rounded-control text-left"
        >
          <span className="text-meta text-apagado">{titulo}</span>
          <span className="text-cuerpo font-semibold text-tinta">{actual.etiqueta}</span>
          {actual.frase ? <span className="text-meta text-tinta">{`«${actual.frase}»`}</span> : null}
        </button>
      ) : (
        <div className="flex min-h-objetivo flex-wrap items-center justify-between gap-2">
          <span className="text-meta text-apagado">{titulo}</span>
          {abierto ? null : (
            <Boton
              variante="secundario"
              tamano="chico"
              aria-expanded={false}
              aria-controls={panel}
              onClick={() => setAbierto(true)}
            >
              Agregar<span className="sr-only">{` ${titulo}`}</span>
            </Boton>
          )}
        </div>
      )}
      {actual?.certezaBaja ? <p className="text-meta text-apagado">{CERTEZA_BAJA}</p> : null}
      {actual?.porQue ? <p className="text-meta text-apagado">{`Por qué: ${actual.porQue}`}</p> : null}
      {actual?.revision ? <p className="text-meta font-semibold text-tinta">{actual.revision}</p> : null}

      {abierto ? (
        <form
          id={panel}
          aria-label={titulo}
          className="grid gap-3 border-t border-hilo pt-3"
          onSubmit={(evento) => {
            evento.preventDefault()
            guardar()
          }}
        >
          {opciones.map((grupo) => (
            <fieldset key={grupo.titulo ?? "lista"} className="grid">
              <legend className="text-meta font-semibold text-apagado">{grupo.titulo ?? titulo}</legend>
              <div className="elecciones grid">
                {grupo.opciones.map((opcion) => (
                  <Eleccion
                    key={opcion.valor}
                    nombre={`${id}-valor`}
                    valor={opcion.valor}
                    elegido={elegido === opcion.valor}
                    etiqueta={opcion.etiqueta}
                    detalle={opcion.detalle ?? undefined}
                    alElegir={setElegido}
                  />
                ))}
              </div>
            </fieldset>
          ))}
          {conFrase ? (
            <div className="grid gap-1.5">
              <label htmlFor={`${id}-frase`} className="text-cuerpo font-semibold">
                Frase
              </label>
              <input
                id={`${id}-frase`}
                className={CLASES_DE_CAMPO}
                value={frase}
                maxLength={500}
                onChange={(evento) => setFrase(evento.target.value)}
              />
            </div>
          ) : null}
          {pidePorQue(elegido) ? (
            <div className="grid gap-1.5">
              <label htmlFor={`${id}-por-que`} className="text-cuerpo font-semibold">
                ¿Por qué? En una línea
              </label>
              <input
                id={`${id}-por-que`}
                className={CLASES_DE_CAMPO}
                value={porQue}
                maxLength={500}
                onChange={(evento) => setPorQue(evento.target.value)}
              />
            </div>
          ) : null}
          <div className="flex flex-wrap gap-2">
            {actual ? (
              <Boton
                variante="secundario"
                tamano="chico"
                cargando={pendiente}
                onClick={() => ejecutar(() => confirmarEtiquetaAccion({ afirmacionId, campo, red, marcaId }), cerrar)}
              >
                Está bien
              </Boton>
            ) : null}
            <Boton type="submit" tamano="chico" cargando={pendiente}>
              {actual ? "Cambiar" : "Guardar"}
            </Boton>
            <Boton variante="callado" tamano="chico" onClick={cerrar}>
              Cerrar
            </Boton>
          </div>
          {quitable && actual && marca ? (
            quitando ? (
              <ConfirmacionEnLinea
                trato="destructivo"
                pregunta="¿Quito esta marca? Queda anotado que la quitaste."
                confirmar="Quitar"
                volver="Volver"
                cargando={pendiente}
                error={error}
                alConfirmar={() => ejecutar(() => quitarMarcaAccion({ afirmacionId, marca, red, marcaId }), cerrar)}
                alVolver={() => setQuitando(false)}
              />
            ) : (
              <Boton variante="callado" tamano="chico" onClick={() => setQuitando(true)}>
                Quitar
              </Boton>
            )
          ) : null}
          {problema ? <LineaDeError>{problema}</LineaDeError> : null}
        </form>
      ) : null}
    </div>
  )
}
```

```tsx
 * The marks of one field and network: one editor per row, or «Agregar» when there is none. Keyed by what the row
 * says, so the refreshed page remounts an editor whose value changed and its form starts from the new one.

function Marcas({
  afirmacion,
  catalogo,
  campo,
  red,
  filas,
}: {
  afirmacion: AfirmacionLeida
  catalogo: CatalogoDeEtiquetas
  campo: MarcaLeida["marca"]
  red: Red | "todas"
  filas: readonly MarcaLeida[]
}) {
  const comun = {
    afirmacionId: afirmacion.id,
    campo,
    red,
    titulo: tituloDeEtiqueta(campo, red),
    opciones: opcionesDe(catalogo, campo, red),
    conFrase: true,
  }
  if (filas.length === 0) return <EditorDeEtiqueta {...comun} marcaId={null} actual={null} quitable={false} />

      {...comun}

      actual={actualDeMarca(fila, catalogo, afirmacion.correcciones)}
      quitable
    />
  ))
}
```

```tsx
  searchParams,
}: {
```
