# Plan 5a: App core (login, Inicio, Guion, Video) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Checkbox steps.

**Goal:** Coni signs in with an emailed code from the installed PWA, sees what needs her signature, approves scripts (gate 1) and videos with a date (gate 2) by sliding, and every action reaches the database through authenticated Server Actions that run the domain state machine and trigger the background tasks.

**Design (approved, binding):** `docs/DESIGN.md` (tokens, components, rules), `docs/PRODUCT.md` (users, principles, a11y), `docs/estudio-coni-propuestas.html` (directions marked "Elegida": Inicio = lista serena; Guion = carta on the pillar tint, pillar strip on top, "Si lo apruebas hoy, sale el ..." line; Video = full-bleed 9:16 player, review panel appears after watching to the end) and `docs/estudio-coni-propuestas-2.html` (Ingreso = six OTP boxes). Design doc `~/Projects/coni-heygen/docs/designs/plataforma-coni.md` "Design Review" section: information architecture (Pass 1), states table (Pass 2), journey (Pass 3), a11y (Pass 6), 3-tab nav Inicio/Métricas/Ajustes. Load the `impeccable` and `emil-design-eng` skills before writing UI. Young Serif only for titles and the script; Hanken Grotesk for everything else; 18 px base; 52 px primary buttons; 44 px targets; raspberry `#b3285f` is the only action color; no `#fff`/`#000`; no em dashes in copy; light theme.

**Architecture:** Next.js 16 App Router (check `node_modules/next/dist/docs` for v16 specifics, e.g. `proxy.ts` replacing `middleware.ts`, async `cookies()`), Tailwind v4 tokens in `app/globals.css` from DESIGN.md, `next/font/google` for the two families. Server Actions in `app/(app)/**/acciones.ts` call `lib/acciones/*.ts` (pure-ish functions with injected `db` + `disparar` so they are unit/integration testable). Approvals run as Coni (her session's Supabase client) so the DB triggers record her; tasks are triggered with `tasks.trigger` from `@trigger.dev/sdk` using global idempotency keys (`claveIdempotencia`).

### Task 1: Shell, tokens, fonts, PWA
`app/layout.tsx` (lang `es-CL`, metadata "Estudio de Coni", viewport, theme color), `app/globals.css` with DESIGN.md tokens as CSS variables + Tailwind v4 `@theme`, `app/manifest.ts` (standalone, icons placeholder generated as simple SVG/PNG from tokens), `components/nav-inferior.tsx` (Inicio, Métricas, Ajustes; Métricas/Ajustes routes render a placeholder "Muy pronto" until Plan 5b), base components from DESIGN.md: `Boton`, `PildoraPilar`, `MarcaRevision`, `Aviso` (toast). Remove the template page. Test: render tests (Testing Library) for components (accessible names, 44 px min via class), `pnpm build`. Commit "feat(app): shell, design tokens and PWA manifest".

### Task 2: Sign-in with an emailed code
`app/ingreso/page.tsx` + `lib/acciones/ingreso.ts`: step 1 shows the masked email and "Mandarme el código" (single user; the server only accepts the address in `AVISOS_CORREO_CONI`/`CORREO_CONI`, and `signInWithOtp({ email, options: { shouldCreateUser: false } })`); step 2 six boxes (`autocomplete="one-time-code"` on the first, numeric keyboard, paste fills all), `verifyOtp({ email, token, type: "email" })`, then redirect to `/`. Session refresh in `proxy.ts` (or `middleware.ts` if v16 docs say so) with `@supabase/ssr`; every `(app)` route requires a session whose user is Coni (`es_coni()`); the maintainer and anyone else get a plain "Esta app es solo para Coni." page. Local config: Supabase email OTP enabled with 6 digits in `supabase/config.toml`; seed Coni's email. Errors from the states table (wrong/expired code, too many attempts). Tests: unit for code-box behaviour; integration/E2E (Task 6) does the real OTP through the local mail catcher (Mailpit/Inbucket API on port 54424). Commit "feat(app): sign in with an emailed code".

### Task 3: Server Actions core
`lib/acciones/piezas.ts` with injected `{ db (Coni's client), disparar, ahora }`: `elegirIdeas(ids)` (creates pieces from ideas, `elegir` transition, marks ideas `usada`, triggers `producir-pieza`), `aprobarGuion(piezaId, versionVista)` (reads row, recomputes `hashPuerta1` from the row, `transicionar(aprobar_guion)` with `hashVisto` = hash of what the screen showed (passed from the client as the version she saw → refuse if `version` changed), update with version check, trigger `grabar-pieza`), `pedirCambios`, `editarTexto(texto)` (runs `revisarGuion` deterministic inline and stores the new revision through a service-role helper since only the server writes `revision`; caption-only edit per R2-5), `aprobarVideo(piezaId, versionVista, publicarEn)` (date in `America/Santiago` converted to UTC with an explicit offset; must be in the future), `regrabar`, `cambiarFecha`, `descartar` (cancel effect: if `programado`, nothing remote to cancel with Graph API direct; document), `reintentar`. Every action catches `Falla` and returns `{ error: mensaje }` (Next redacts thrown messages); `FallaDeConfiguracion`/`AprobacionNoAutorizada`/unknown → generic Spanish error + server log. CRLF→LF and NFC normalization of edited text at this boundary (carried). Integration tests against local DB with a fake `disparar`: each action's happy path, stale version → error message, approvals recorded with Coni's id, service-role cannot be used by these actions, blocking review → refused. Commit "feat(acciones): server actions for the two gates".

### Task 4: Inicio
`app/(app)/page.tsx`: "Hola, Coni", week summary, "Necesita tu firma" list (guion / video rows open the detail; no approve buttons in the list, A11), "En camino" (grabando/programado with progress hint), "Ideas de la semana" (5 suggested ideas, choose 3 → `elegirIdeas`), consultas counter placeholder (Plan 6). States from the Pass 2 table: skeleton loading, empty ("Nada espera tu firma esta semana..."), error notice with cause and action, success notices, partial. Commit "feat(app): inicio".

### Task 5: Guion and Video screens
`app/(app)/guion/[id]/page.tsx`: pillar strip, title in serif, "Si lo apruebas hoy, sale el ..." line, the script as a letter on the pillar tint (Young Serif), voice player (signed R2 URL via service-role server helper, never exposing keys), "Así sale en Instagram" with the caption (editable → `editarTexto`), review findings (`MarcaRevision`: bloquea items must be fixed; advierte items need "Lo revisé y está bien" ticks), cost line, slide-to-approve (`input type=range`, approves at 96 %, `aria-valuetext`, keyboard End) disabled until the voice was played and warnings confirmed and no blocking findings; "Pedir cambios". `app/(app)/video/[id]/page.tsx`: full-bleed 9:16 player with "Avatar IA" label and "Ver zonas de Instagram" toggle, review panel appears after 95 % watched (no forward seeking counted), checklist, caption, proposed date (next Tue/Thu/Sat 19:00 Santiago, editable), slide "aprobar video y fecha", "Regrabar". Commit "feat(app): guion and video screens with slide to approve".

### Task 6: E2E and verification

Run lint/type/test:run/test:db/build/e2e. Append "Execution notes". Commit "test(e2e): coni approves script and video".
