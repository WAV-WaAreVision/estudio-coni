# Conidolly ingestion module (Plan B). Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate web app, `conidolly-ingesta.vercel.app`, where Coni and WAV upload material (documents, links, audio, video, images, posts). Video is read on two tracks: what is said (Scribe) and the text burned on screen (frames read by Claude vision). The material is turned into cards, linked in a graph, synthesized into theories, and offered as inspiration sources on the Conidolly Guion screen.

**Architecture:** Spec: `docs/superpowers/specs/2026-10-02-conidolly-ingesta-design.md` (Plan B section). Same Supabase project, R2 bucket and Trigger.dev project as Conidolly. Schema migrations and Trigger tasks live in `estudio-coni`; the new repo `conidolly-ingesta` holds only the web app and generates its types from the shared database. Embeddings with Voyage `voyage-3.5` (1024 dimensions) in pgvector; transcription with ElevenLabs Scribe; cards, link classification and theories with Claude.

**Tech Stack:** Next.js 16 App Router, Supabase (Postgres, RLS, pgvector), Trigger.dev v4, Cloudflare R2 (S3 SigV4), Tailwind v4, Vitest, Playwright, Biome, `unpdf`, `mammoth`, `@mozilla/readability` with the existing `jsdom`, Cytoscape.js.

**Three phases, in order, each shippable on its own:**
- **B1 (tasks 1-9):** schema, upload, processing, cards, materials screens.
- **B2 (tasks 10-14):** embeddings, link suggestions, graph screen, theories.
- **B3 (tasks 15-17):** source picker on the Conidolly Guion screen, inspiration-only prompt, copy-check rule, gate-1 formula 3.

**Rules (as in every plan of this repo):** strict TDD (failing test first, seen red); one commit per task ending with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; never `as any`, `@ts-expect-error`, non-null assertions or silent catches; Biome safe mode only and `"use client"` on line 1; semantic tokens only; copy in Spanish of Chile, `tú`, no em dashes; no real network in tests (MSW); migrations in range `20261003000100`-`20261003000999`; never run anything against the hosted project (`mvfytttfxmzzjajecsch`). In `estudio-coni`: `pnpm lint`, `pnpm type`, `pnpm test:run`, `pnpm test:db`, `pnpm build`, `pnpm db:types` after `supabase db reset`, E2E with `PLAYWRIGHT_CHROMIUM_PATH=~/Library/Caches/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-mac-arm64/chrome-headless-shell pnpm test:e2e`. If sign-in E2E fails after a reset: `supabase stop && supabase start`.

**Language rule:** every transcription or extracted text (speech, on-screen text, images, documents, links) ends in Spanish of Chile. The original-language text is kept as `materiales/<id>/texto-original.txt` for reference; the Chilean Spanish version `materiales/<id>/texto.txt` is what cards, quotes, embeddings, links, theories and scripts use. Text already in Spanish (any variant) is kept verbatim, not rewritten, so quotes stay faithful. `materiales.idioma_original` (ISO 639-1, detected) records the source language.

**Third-party content rule:** the app never downloads from Instagram, TikTok or similar; the user uploads the file. Third-party material stays private in R2 and is used only as inspiration (Phase B3 rules: no quoting, no authors, copy check).
