# Batch Actions (Part 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Coni chooses or discards several ideas in one go (with a whole-batch cap check and an 8 s undo for the
discard), and the Agenda proposes dates for every piece that has not passed gate 2, which gate 2 preselects and gate 1
shows as the estimate, without ever touching a signature.

**Architecture:** One migration (`20261017000400_lote.sql`) stamps who and when discarded an idea, adds the atomic
`descartar_ideas` and the 8 s `restaurar_ideas`, and adds the table `fechas_propuestas` (one row per piece, audited,
written only through `proponer_fechas`). A pure module `lib/calendario/propuestas.ts` decides where every unsigned
piece goes (`repartir`): stored proposals that are still free first, then the next free rhythm slots. The Agenda
model, the `Repartir fechas` action and the gates all read that one function. The Ideas screen gets a third view,
`Elegir varias`, with checkbox rows and a sticky batch bar (`components/barra-de-lote.tsx`).

**Tech Stack:** Next.js 16 App Router (Server Components + Server Actions), Supabase Postgres (RLS, plpgsql security
definer functions, audit trigger), Vitest + Testing Library, Playwright + axe, Biome, pnpm.

## Amendments to the spec (verified against `main` at 5aedc83; where the spec and this block disagree, this block wins)

- **A1. Where "choose several" lives.** Inicio already chooses up to 5 ideas at once (`app/(app)/ideas-semana.tsx` ->
  `elegirIdeasAccion` -> `elegirIdeas`, `lib/acciones/piezas.ts:163`, `MAXIMO_DE_IDEAS = 5` in `lib/dominio/ideas.ts`).
  The Ideas screen (`app/(app)/ideas/banco-de-ideas.tsx`) is a one-at-a-time deck plus a search list; its "Usar esta"
  only pins an idea for Inicio. `Elegir varias` is a third view of that screen: the free ideas as checkbox rows
  (`components/ui/casilla.tsx`), not checkboxes on the deck card (a deck shows one card).
- **A2. Cap check for the batch.** Nothing estimates a batch today. One script reserves Claude's US$ 0.50
  (`ESTIMADO_CLAUDE_USD`, `lib/produccion/producir.ts:60`) and then her voice of the draft (`estimarCostoVoz`,
  `lib/produccion/comun.ts:51`, US$ 0.0003 per character). The batch uses a conservative per-script estimate: 0.50 plus
  the voice of the longest script allowed (`MAXIMO_DEL_GUION = 2000` characters, US$ 0.60), US$ 1.10. The check reads
  `leerPresupuesto` (`lib/datos/pantallas.ts:89`) and follows the SQL rule of `reservar_gasto` (refuses when `usado +
  estimado > tope`). It is advisory: the real guard stays the reservation inside `producir-pieza`, which leaves
  `TEXTO_TOPE` on the piece. The constant moves to `lib/produccion/comun.ts` (same value) so both read one number.
- **A3. `elegirIdeas` stays as Inicio uses it.** A new `elegirLote` validates the same way, checks the cap and then
  runs the same starter (`empezarIdeas`, extracted from `elegirIdeas` with no behaviour change). Every script still
  goes to its own gate 1; each piece records `elegir` through `guardarEvento` as today.
- **A4. Discard time and author.** `ideas` has no discard timestamp (`database.types.ts`, Row of `ideas`), so the undo
  window has nothing to measure. New columns `ideas.descartada_en` and `ideas.descartada_por`, stamped with `now()` and
  `auth.uid()` by `descartar_idea` (replaced, same signature and errors) and by the new `descartar_ideas(p_ids uuid[],
  p_motivo text)`, which is all or nothing (1 to 5 distinct ids; `no_descartable` if any left the bank meanwhile).
  `restaurar_ideas(p_ids uuid[]) returns uuid[]` is `es_coni()` only and brings back only ideas that are
  `descartada`, not `pilar_retirado`, discarded by the caller (`descartada_por = auth.uid()`), less than 8 s ago by the
  database clock, and whose pillar is still active (a pillar retired inside those 8 s keeps the idea out). It returns
  the ids it brought back. It clears the motive, the time and the author; a pin removed by the discard is not restored.
- **A5. The window is strict.** 8 s on the database clock, no margin (spec wording; the gate 1 undo has no margin
  either). A late tap reads `Ya pasaron los 8 segundos: quedaron descartadas.`
- **A6. `fecha_propuesta` is a table, not a column of `piezas`.** Every update of `piezas` must bump `version`
  (`proteger_pieza`, latest in `20261006000100_destinos.sql`), so writing a proposal would invalidate an open screen
  (`PantallaVencida`) and the optimistic writes of the running tasks (the writer saves with `versionLeida`). Every
  update of `piezas` is also logged whole in `eventos` (`registrar_evento`, `20261001000300_puertas_y_auditoria.sql`),
  and `docs/metricas-friccion.sql` counts rows, not transitions: `pedir_cambios` counts `guion_en_proceso` rows and
  `refirmas` counts `en_render` rows written by `authenticated`, so a proposal written while a piece sits there would
  read as rework. New table `fechas_propuestas (pieza_id pk -> piezas on delete cascade, publicar_en, propuesta_en)`,
  read by Coni and WAV, written only through `proponer_fechas(p_piezas uuid[], p_fechas timestamptz[])` (`es_coni()`
  only, every piece in a state before gate 2, every date in the future), audited with `registrar_evento` (one
  `eventos` row per piece, `tabla = 'fechas_propuestas'`). It is outside every signature hash and every version lock
  by construction. `docs/metricas-friccion.sql` does not change.
- **A7. The Agenda already places unsigned pieces.** `construirAgenda` (`lib/calendario/modelo.ts`) puts every piece
  without a date in the next free slots, the closest to publishing first (`ORDEN_EN_CAMINO`), labelled `lugar
  propuesto`; `tests/unit/calendario-modelo.test.ts` and `tests/e2e/calendario.spec.ts` cover it. The spec missed it.
  This plan keeps it and makes stored proposals win: a stored proposal that is still free (at least 2 h ahead, no
  signed piece at that time, not already given to a piece earlier in the order) holds its slot and reads `propuesta`
  with `Cambiar`; the other unsigned pieces keep today's placement in the remaining free slots. `Repartir fechas`
  stores exactly what the Agenda shows, so it uses the Agenda's order (closest to publishing, then creation) instead of
  plain creation order. A stale proposal is ignored on read and the piece falls back to today's placement (it is not
  listed as `sin fecha`); at the gates it falls back to today's computation.
- **A8. Range of `Repartir` and `Cambiar`.** `Repartir fechas` covers every unsigned piece, not only the 4 weeks the
  Agenda shows (it uses `proponerFechas` with no horizon). `Cambiar` offers the next 3 slots no piece holds (signed,
  stored or shown); the server accepts any schedule slot at least 2 h ahead within the next 60 that no signed piece and
  no other stored proposal holds, and says `Ese espacio ya no está libre. Elige otro.` otherwise.
- **A9. The gates.** Gate 2 (`app/(app)/video/[id]/page.tsx`) preselects `datos.fechas[0]`; the stored proposal goes
  first when it is at least 1 h ahead (gate 2's `UNA_HORA_MS`) and no `programado` piece holds it
  (`leerContextoDeFechas.ocupadas`), otherwise the list is today's. Gate 1 (`app/(app)/guion/[id]/page.tsx`) shows the
  proposal in `Si lo firmas hoy, sale el ...` when it is at least 12 h ahead (`DOCE_HORAS_MS`) and free, otherwise
  today's `propuestas[enCola]`. Nothing at gate 2 changes what is signed: `puerta2_publicar_en` is still the date she
  slides on.
- **A10. Audit (decision 26).** Discards and restores update `ideas` row by row, so `eventos` gets one row per idea
  (`tabla = 'ideas'`), as a single discard does today. Starting scripts records `elegir` per piece as today. Proposals
  log one row per piece in `fechas_propuestas`. The friction query reads `tabla = 'piezas'` only and keeps working.
- **A11. Toast placement.** In `Elegir varias` the toast goes to the top (`lugar="arriba"`), so it never covers the
  batch bar that sits above the bottom nav.
- **A12. Trigger.dev.** No task changes behaviour: `lib/produccion/producir.ts` only imports the moved constant (same
  value). No Trigger deploy is needed for this part.

```ts
// tests/integration/lote-esquema.test.ts
import { readFileSync } from "node:fs"
import { join } from "node:path"
import type pg from "pg"
import { afterAll, describe, expect, it } from "vitest"
import { VENTANA_DESHACER_MS } from "@/lib/dominio/estados"
import {
  asumir,
  CONI,
  como,
  comoConi,
  comoMantenedor,
  comoOtra,
  comoPostgres,
  comoServicio,
  fallaCon,
  MANTENEDOR,
  pool,
} from "./db"

afterAll(() => pool.end())

type Cliente = pg.PoolClient
const MIGRACION = readFileSync(join(process.cwd(), "supabase/migrations/20261017000400_lote.sql"), "utf-8")

async function crearIdea(c: Cliente, pilar = "ia-salud-mental"): Promise<string> {
  const { rows } = await c.query<{ id: string }>(
    `insert into public.ideas (pilar, gancho, tema, formato, fuerza, estado, origen, fijada_en)
     values ($1, 'Gancho', 'Tema', 'reel', 'media', 'idea', 'motor', now()) returning id`,
    [pilar],
  )
  const fila = rows[0]
  if (!fila) throw new Error("No se creó la idea")
  return fila.id
}

async function idea(c: Cliente, id: string) {
  const { rows } = await c.query(
    "select estado, motivo_descarte, fijada_en, descartada_en, descartada_por from public.ideas where id = $1",
    [id],
  )
  return rows[0]
}

describe("descartar_ideas", () => {
  it("discards every idea of the batch with one motive, stamps who and when, and unpins them", async () => {
    await como(comoPostgres, async (c) => {
      const [a, b] = [await crearIdea(c), await crearIdea(c)]
      await asumir(c, comoConi)
      await c.query("select public.descartar_ideas($1::uuid[], 'repetida')", [[a, b]])
      await asumir(c, comoPostgres)
      for (const id of [a, b]) {
        expect(await idea(c, id)).toMatchObject({
          estado: "descartada",
          motivo_descarte: "repetida",
          fijada_en: null,
          descartada_por: CONI,
        })
        expect((await idea(c, id)).descartada_en).toBeInstanceOf(Date)
      }
    })
  })

  it("discards none when one of them already left the bank", async () => {
    await como(comoPostgres, async (c) => {
      const [libre, usada] = [await crearIdea(c), await crearIdea(c)]
      await c.query("update public.ideas set estado = 'usada' where id = $1", [usada])
      await asumir(c, comoConi)
      const error = await fallaCon(c, "select public.descartar_ideas($1::uuid[], 'debil')", [[libre, usada]])
      expect(error).toMatchObject({ code: "22023", message: "no_descartable" })
      await asumir(c, comoPostgres)
      expect((await idea(c, libre)).estado).toBe("idea")
    })
  })

  it("refuses an empty batch, more than five, a repeated id or a null with lote_invalido", async () => {
    await como(comoPostgres, async (c) => {
      const id = await crearIdea(c)
      await asumir(c, comoConi)
      for (const ids of [[], [id, id], Array.from({ length: 6 }, () => id), [id, null]]) {
        const error = await fallaCon(c, "select public.descartar_ideas($1::uuid[], 'debil')", [ids])
        expect(error).toMatchObject({ code: "22023", message: "lote_invalido" })
      }
    })
  })

  it("refuses an unknown motive, pilar_retirado included", async () => {
    await como(comoPostgres, async (c) => {
      const id = await crearIdea(c)
      await asumir(c, comoConi)
      for (const motivo of ["nada", "pilar_retirado"]) {
        const error = await fallaCon(c, "select public.descartar_ideas($1::uuid[], $2)", [[id], motivo])
        expect(error).toMatchObject({ code: "22023", message: "motivo_invalido" })
      }
    })
  })

  it("lets the maintainer discard and refuses anyone else and the service role", async () => {
    await como(comoPostgres, async (c) => {
      const [a, b] = [await crearIdea(c), await crearIdea(c)]
      await asumir(c, comoOtra)
      expect((await fallaCon(c, "select public.descartar_ideas($1::uuid[], 'debil')", [[a]])).code).toBe("42501")
      await asumir(c, comoServicio)
      expect((await fallaCon(c, "select public.descartar_ideas($1::uuid[], 'debil')", [[a]])).code).toBe("42501")
      await asumir(c, comoMantenedor)
      await c.query("select public.descartar_ideas($1::uuid[], 'otro')", [[b]])
      await asumir(c, comoPostgres)
      expect((await idea(c, b)).descartada_por).toBe(MANTENEDOR)
    })
  })
})

describe("descartar_idea after the batch migration", () => {

describe("restaurar_ideas", () => {
  it("brings back what Coni discarded inside the window and clears the motive, the time and the author", async () => {
    await como(comoPostgres, async (c) => {
      const [a, b] = [await crearIdea(c), await crearIdea(c)]
      await asumir(c, comoConi)
      await c.query("select public.descartar_ideas($1::uuid[], 'debil')", [[a, b]])
      const { rows } = await c.query<{ vueltas: string[] }>(
        "select public.restaurar_ideas($1::uuid[]) as vueltas",
        [[a, b]],
      )
      expect([...(rows[0]?.vueltas ?? [])].sort()).toEqual([a, b].sort())
      await asumir(c, comoPostgres)
      expect(await idea(c, a)).toMatchObject({
        estado: "idea",
        motivo_descarte: null,
        descartada_en: null,
        descartada_por: null,
      })
    })
  })

  it("leaves out an idea discarded more than 8 seconds ago by the database clock", async () => {
    await como(comoPostgres, async (c) => {
      const [reciente, vieja] = [await crearIdea(c), await crearIdea(c)]
      await asumir(c, comoConi)
      await c.query("select public.descartar_ideas($1::uuid[], 'debil')", [[reciente, vieja]])
      await asumir(c, comoPostgres)
      await c.query("update public.ideas set descartada_en = now() - interval '9 seconds' where id = $1", [vieja])
```

```ts
  if (ideaIds.length === 0 || ideaIds.length > MAXIMO_DE_IDEAS || new Set(ideaIds).size !== ideaIds.length) {

/** Claims every idea and starts its script, in the order given. Every script then goes to its own gate 1. */
async function empezarIdeas(deps: DepsAcciones, ideaIds: readonly string[]): Promise<string[]> {
  const noDisponible = new Falla("Una de esas ideas ya no está disponible. Vuelve a elegir.")
  const { data: ideas, error } = await deps.db
    .from("ideas")
    .select("id, gancho, estado")
    .in("id", [...ideaIds])
  if (error) throw new Error(`No pude leer las ideas: ${error.message}`, { cause: error })
  if (ideas.length !== ideaIds.length || ideas.some((idea) => idea.estado !== "idea")) throw noDisponible

  const piezas: string[] = []
  for (const id of ideaIds) {
    const idea = ideas.find((candidata) => candidata.id === id)
    if (!idea) throw noDisponible
    piezas.push(await empezarPieza(deps, idea, noDisponible))
  }
  return piezas
}

export function elegirIdeas(deps: DepsAcciones, ideaIds: readonly string[]): Promise<Resultado<{ piezas: string[] }>> {
  return aResultado("elegirIdeas", async () => {
    exigirLoteDeIdeas(ideaIds)
    return { piezas: await empezarIdeas(deps, ideaIds) }
  })
}

export type LoteElegido = { tipo: "empezadas"; piezas: string[] } | { tipo: "alcanza"; cuantas: number }

/**
 * "Hacer los guiones (N)" on Ideas (decision 23): the month is checked for the whole batch first. When it covers
 * fewer, nothing starts and she is told how many fit; she asks again for those. The reservation inside the writer
 * stays the real guard (amendment A2).
 */
export function elegirLote(deps: DepsAcciones, ideaIds: readonly string[]): Promise<Resultado<LoteElegido>> {
  return aResultado("elegirLote", async (): Promise<LoteElegido> => {
    exigirLoteDeIdeas(ideaIds)
    const { data, error } = await deps.db.from("ajustes").select("zona").maybeSingle()
    if (error) throw new Error(`No pude leer la zona: ${error.message}`, { cause: error })
    const presupuesto = await leerPresupuesto(deps.db, Date.parse(deps.ahora()), data?.zona ?? "America/Santiago")
    const alcanza = cuantasAlcanzan({
      ...presupuesto,
      estimadoPorGuion: ESTIMADO_POR_GUION_USD,
      pedidas: ideaIds.length,
    })
    if (alcanza === 0) throw new Falla(TEXTO_TOPE)
    if (alcanza < ideaIds.length) return { tipo: "alcanza", cuantas: alcanza }
    return { tipo: "empezadas", piezas: await empezarIdeas(deps, ideaIds) }
  })
```

```ts
const UnaDeEsasNoEsta = new Falla("Una de esas ideas ya no está disponible. Vuelve a elegir.")
const LoteDeIdeas = z.array(z.uuid()).min(1).max(MAXIMO_DE_IDEAS)
const ERROR_LOTE = `Elige entre una y ${MAXIMO_DE_IDEAS} ideas distintas.`
const DescarteDeLote = z.object({ ideaIds: z.array(z.uuid()), motivo: z.enum(MOTIVOS_DE_DESCARTE) })

/** "Descartar (N)" (decision 24): one motive for the whole batch; all of them leave the bank or none does. */
export function descartarIdeas(deps: DepsIdeas, entrada: unknown): Promise<Resultado> {
  return aResultado("descartarIdeas", async () => {
    const descarte = DescarteDeLote.safeParse(entrada)
    if (!descarte.success) throw new Falla("Elige por qué las descartas.")
    const ids = LoteDeIdeas.safeParse(descarte.data.ideaIds)
    if (!ids.success || new Set(ids.data).size !== ids.data.length) throw new Falla(ERROR_LOTE)
    const { error } = await deps.db.rpc("descartar_ideas", { p_ids: ids.data, p_motivo: descarte.data.motivo })
    if (error?.message === "no_descartable") throw UnaDeEsasNoEsta
    if (error?.message === "lote_invalido") throw new Falla(ERROR_LOTE)
    if (error) throw new Error(`No pude descartar las ideas: ${error.message}`, { cause: error })
    return {}
  })
}

/** "Deshacer" of the batch discard: the database brings back what is still inside the 8 s and says which. */
export function restaurarIdeas(deps: DepsIdeas, ideaIds: readonly string[]): Promise<Resultado<{ restauradas: string[] }>> {
  return aResultado("restaurarIdeas", async () => {
    const ids = LoteDeIdeas.safeParse(ideaIds)
    if (!ids.success) throw new Falla(ERROR_LOTE)
    const { data, error } = await deps.db.rpc("restaurar_ideas", { p_ids: ids.data })
    if (error) throw new Error(`No pude devolver las ideas al banco: ${error.message}`, { cause: error })
    return { restauradas: data ?? [] }
  })
}
```

```tsx
export interface AccionesDeEleccion {
  elegirVarias: (ideaIds: string[]) => Promise<Resultado<LoteElegido>>
  descartarVarias: (ideaIds: string[], motivo: MotivoDeDescarte) => Promise<Resultado>
  restaurar: (ideaIds: string[]) => Promise<Resultado<{ restauradas: string[] }>>
}

interface Mensaje {
  texto: string
  deshacer?: () => void
}

/**
 * Decisions 23 and 24: the free ideas as rows to tick, up to five, and one bar for what to do with them. Nothing
 * starts until she taps, and a smaller batch the month can pay for is asked, never assumed. The toast goes to the
 * top so it never covers the bar (amendment A11).
 */
export function EleccionDeIdeas({
  ideas,
  acciones,
  alSacar,
  alDevolver,
}: {
  ideas: readonly IdeaDeBanco[]
  acciones: AccionesDeEleccion
  /** They left the bank from here (started or discarded): the screen stops offering them. */
  alSacar: (ideaIds: string[]) => void
  /** They came back with Deshacer. */
  alDevolver: (ideaIds: string[]) => void
}) {
  const [elegidas, setElegidas] = useState<string[]>([])
  const [alcanza, setAlcanza] = useState<number | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [mensaje, setMensaje] = useState<Mensaje | null>(null)
  const [deshaciendo, setDeshaciendo] = useState(false)
  const [pendiente, empezar] = useTransition()
  const cerrarMensaje = useCallback(() => setMensaje(null), [])

  const enElMaximo = elegidas.length >= MAXIMO_DE_IDEAS
  const cuantas = elegidas.length

  function cambiar(ideaId: string, marcada: boolean) {
    setError(null)
    setAlcanza(null)
    setElegidas((previas) => (marcada ? [...previas, ideaId] : previas.filter((id) => id !== ideaId)))
  }

  function hacer(ideaIds: string[]) {
    setError(null)
    empezar(async () => {
      const resultado = await acciones.elegirVarias(ideaIds)
      if (!resultado.ok) {
        setError(resultado.error)
        return
      }
      if (resultado.tipo === "alcanza") {
        setAlcanza(resultado.cuantas)
        return
      }
      setAlcanza(null)
      setElegidas([])
      alSacar(ideaIds)
      setMensaje({ texto: textoDeEmpezadas(resultado.piezas.length) })
    })
  }

  function descartar(motivo: MotivoDeDescarte) {
    const ideaIds = elegidas
    setError(null)
    empezar(async () => {
      const resultado = await acciones.descartarVarias(ideaIds, motivo)
      if (!resultado.ok) {
        setError(resultado.error)
        return
      }
      setElegidas([])
      setAlcanza(null)
      alSacar(ideaIds)
      setMensaje({ texto: textoDeDescartadas(ideaIds.length), deshacer: () => restaurar(ideaIds) })
    })
  }

  function restaurar(ideaIds: string[]) {
    setDeshaciendo(true)
    empezar(async () => {
      const resultado = await acciones.restaurar(ideaIds)
      setDeshaciendo(false)
      if (!resultado.ok) {
        setMensaje(null)
        setError(resultado.error)
        return
      }
      alDevolver(resultado.restauradas)
      setMensaje({ texto: textoDeRestauradas(resultado.restauradas.length, ideaIds.length) })
    })
  }

  return (
    <div className="grid gap-4">
      <p className="text-meta text-apagado">
        Elige hasta {MAXIMO_DE_IDEAS} ideas para hacer sus guiones o descartarlas juntas.
      </p>
      {error && cuantas === 0 ? <LineaDeEstado tipo="error" titulo={error} /> : null}
      {ideas.length === 0 ? (
        <p className="text-cuerpo font-semibold">No quedan ideas libres en el banco.</p>
      ) : (
        <Grupo lista>
          {ideas.map((idea) => {
            const marcada = elegidas.includes(idea.id)
            return (
              <li key={idea.id}>
                <Casilla
                  etiqueta={idea.gancho}
                  detalle={`${idea.nombrePilar} · Fuerza ${idea.fuerza}`}
                  marcada={marcada}
                  deshabilitada={!marcada && enElMaximo}
                  alCambiar={(valor) => cambiar(idea.id, valor)}
                />
              </li>
            )
          })}
        </Grupo>
      )}
      {enElMaximo ? <p className="text-meta text-apagado">Llegaste al máximo de {MAXIMO_DE_IDEAS}.</p> : null}

      {cuantas > 0 ? (
        <BarraDeLote titulo="Ideas elegidas">
          {error ? <LineaDeEstado tipo="error" titulo={error} /> : null}
          {alcanza !== null ? (
            <>
              <p className="text-cuerpo font-semibold">{preguntaDeAlcance(alcanza)}</p>
              <p className="text-meta text-apagado">
                Hago los primeros {alcanza} que elegiste. El resto queda en el banco.
              </p>
              <Boton cargando={pendiente} onClick={() => hacer(elegidas.slice(0, alcanza))}>
                {botonDeAlcance(alcanza)}
              </Boton>
              <Boton variante="secundario" tamano="chico" className="w-fit" onClick={() => setAlcanza(null)}>
                Volver
              </Boton>
            </>
          ) : (
            <>
              <p className="text-meta font-semibold" aria-live="polite">
                {cuantas === 1 ? "1 elegida" : `${cuantas} elegidas`}
              </p>
              <Boton cargando={pendiente} onClick={() => hacer(elegidas)}>
                Hacer los guiones ({cuantas})
              </Boton>
              <DescartarIdea
                ocupada={pendiente}
                etiqueta={`Descartar (${cuantas})`}
                pregunta="¿Por qué las descartas?"
                alElegir={descartar}
              />
            </>
          )}
        </BarraDeLote>
      ) : null}

      {mensaje ? (
        <Aviso
          lugar="arriba"
          mensaje={mensaje.texto}
          alCerrar={cerrarMensaje}
          alDeshacer={mensaje.deshacer}
          deshaciendo={mensaje.deshacer ? deshaciendo : undefined}
        />
      ) : null}
    </div>
  )
}
```

```ts
// lib/calendario/propuestas.ts
import type { Estado } from "@/lib/dominio/estados"
import { type Horario, proponerFechas } from "@/lib/dominio/fechas"

// Decision 25 (amendments A7 to A9): where every piece that has not passed gate 2 goes. A proposal is a suggestion
// nothing signs: gate 2 signs the date and a signed piece always wins its slot. The Agenda, Repartir and the gates all
// read these functions, so what she sees is what gets stored.

/** Before gate 2, the closest to publishing first: the order the Agenda places them in and Repartir stores them. */
export const ORDEN_SIN_FECHA: Partial<Record<Estado, number>> = {
  video_por_aprobar: 0,
  subtitulando: 1,
  en_render: 1,
  grabando_voz: 1,
  error_produccion: 2,
  guion_aprobado: 2,
  guion_por_aprobar: 3,
  guion_en_proceso: 4,
}

/** Pieces with a signed time: their slot is taken. */
export const ESTADOS_FECHADOS: readonly Estado[] = ["publicado", "programado", "para_subir_a_mano", "publicado_a_mano"]

/** The Agenda offers slots at least this far ahead (design, "Calendario"). */
export const ANTELACION_DE_AGENDA_MS = 2 * 60 * 60 * 1000
/** How far ahead a changed proposal may land, in slots. */
const HUECOS_A_REVISAR = 60

export interface PiezaConFechas {
  id: string
  estado: Estado
  creadaEn: string
  /** The time signed at gate 2. */
  publicarEn: string | null
  /** Her stored proposal (`fechas_propuestas`), live or not. */
  fechaPropuesta: string | null
}

export interface Lugar {
  piezaId: string
  instante: string
  /** Her stored proposal; false is a place the Agenda only shows. */
  guardada: boolean
}

export function sinFechaFirmada(estado: Estado): boolean {
  return ORDEN_SIN_FECHA[estado] !== undefined
}

export function fechasTomadas(piezas: readonly Pick<PiezaConFechas, "estado" | "publicarEn">[]): string[] {
  return piezas.flatMap((pieza) =>
    ESTADOS_FECHADOS.includes(pieza.estado) && pieza.publicarEn !== null ? [pieza.publicarEn] : [],
  )
}

/** A stored proposal holds while it is `antelacionMs` ahead and no signed piece has its time; otherwise null. */
export function propuestaVigente(
  propuesta: string | null,
  entrada: { ahora: number; tomadas: ReadonlySet<number>; antelacionMs: number },
): string | null {
  if (propuesta === null) return null
  const instante = Date.parse(propuesta)
  if (Number.isNaN(instante)) return null
  if (instante < entrada.ahora + entrada.antelacionMs || entrada.tomadas.has(instante)) return null
  return new Date(instante).toISOString()
}

function enOrden(piezas: readonly PiezaConFechas[]): PiezaConFechas[] {
  return piezas
    .filter((pieza) => sinFechaFirmada(pieza.estado))
    .sort(
      (a, b) =>
        (ORDEN_SIN_FECHA[a.estado] ?? 9) - (ORDEN_SIN_FECHA[b.estado] ?? 9) ||
        Date.parse(a.creadaEn) - Date.parse(b.creadaEn),
    )
}

/**
 * Every unsigned piece and its place: first the stored proposals that still hold (one piece per slot, in order), then
 * the next free rhythm slots for the rest, in the same order. No horizon: Repartir covers pieces beyond the Agenda.
 */
export function repartir(entrada: { piezas: readonly PiezaConFechas[]; horario: Horario; ahora: number }): Lugar[] {
  const { horario, ahora } = entrada
  const tomadas = new Set(fechasTomadas(entrada.piezas).map((iso) => Date.parse(iso)))
  const ordenadas = enOrden(entrada.piezas)
  const lugares = new Map<string, Lugar>()
  for (const pieza of ordenadas) {
    const vigente = propuestaVigente(pieza.fechaPropuesta, { ahora, tomadas, antelacionMs: ANTELACION_DE_AGENDA_MS })
    if (vigente === null) continue
    tomadas.add(Date.parse(vigente))
    lugares.set(pieza.id, { piezaId: pieza.id, instante: vigente, guardada: true })
  }
  const sinLugar = ordenadas.filter((pieza) => !lugares.has(pieza.id))
  const libres = proponerFechas({
    ahora,
    horario,
    ocupadas: [...tomadas].map((ms) => new Date(ms).toISOString()),
    cuantas: sinLugar.length,
    antelacionMs: ANTELACION_DE_AGENDA_MS,
  })
  sinLugar.forEach((pieza, i) => {
    const instante = libres[i]
    if (instante) lugares.set(pieza.id, { piezaId: pieza.id, instante, guardada: false })
  })
  return ordenadas.flatMap((pieza) => lugares.get(pieza.id) ?? [])
}

/**
 * The next `cuantas` slots nobody holds. `todos` counts every placed piece (what `Cambiar` offers); `guardados` only
 * stored proposals (what the server accepts), and `excepto` frees that piece's own place.
 */
export function huecosLibres(entrada: {
  piezas: readonly PiezaConFechas[]
  horario: Horario
  ahora: number
  cuantas: number
  contar: "todos" | "guardados"
  excepto?: string
}): string[] {
  const lugares = repartir(entrada).filter(
    (lugar) => lugar.piezaId !== entrada.excepto && (entrada.contar === "todos" || lugar.guardada),
  )
  return proponerFechas({
    ahora: entrada.ahora,
    horario: entrada.horario,
    ocupadas: [...fechasTomadas(entrada.piezas), ...lugares.map((lugar) => lugar.instante)],
    cuantas: entrada.cuantas,
    antelacionMs: ANTELACION_DE_AGENDA_MS,
  })
}

/** `Cambiar` on the server (amendment A8): a schedule slot no signed piece and no other stored proposal holds. */
export function espacioLibreParaCambiar(entrada: {
  piezas: readonly PiezaConFechas[]
  horario: Horario
  ahora: number
  piezaId: string
  instante: string
}): boolean {
  const pedido = Date.parse(entrada.instante)
  return huecosLibres({ ...entrada, cuantas: HUECOS_A_REVISAR, contar: "guardados", excepto: entrada.piezaId }).some(
    (iso) => Date.parse(iso) === pedido,
  )
}

/** Gate 2 preselects the first date (amendment A9): a live proposal goes first, the rest follow as today. */
export function conLaPropuestaPrimero(fechas: readonly string[], propuesta: string | null, cuantas: number): string[] {
  if (propuesta === null) return [...fechas]
  return [propuesta, ...fechas.filter((fecha) => fecha !== propuesta)].slice(0, cuantas)
}

export function textoPorRepartir(cuantas: number): string {
  return cuantas === 1 ? "1 pieza en camino sin fecha propuesta." : `${cuantas} piezas en camino sin fecha propuesta.`
}

export function textoDePropuestas(cuantas: number): string {
  if (cuantas === 0) return "Todas tus piezas ya tienen fecha propuesta."
  return cuantas === 1
    ? "Propuse fecha para 1 pieza. Puedes cambiarla."
    : `Propuse fecha para ${cuantas} piezas. Puedes cambiarlas.`
}
```

```ts
// lib/acciones/fechas.ts
import type { SupabaseClient } from "@supabase/supabase-js"
import { espacioLibreParaCambiar, repartir, sinFechaFirmada } from "@/lib/calendario/propuestas"
import { leerDatosDeCalendario } from "@/lib/datos/calendario"
import { Falla } from "@/lib/dominio/falla"
import type { Database } from "@/lib/supabase/database.types"
import { aResultado, type Resultado } from "./resultado"

type Db = SupabaseClient<Database>

export interface DepsFechas {
  /** Coni's session: `proponer_fechas` is hers only. */
  db: Db
  ahora: () => string
}

const AGENDA_VENCIDA = "La agenda cambió mientras la mirabas. Vuelve a intentarlo."
const ESPACIO_TOMADO = "Ese espacio ya no está libre. Elige otro."

async function proponer(db: Db, piezas: string[], fechas: string[]): Promise<void> {
  const { error } = await db.rpc("proponer_fechas", { p_piezas: piezas, p_fechas: fechas })
  // A piece passed gate 2, or a time passed, between the read and the write.
  if (error?.message === "propuesta_invalida") throw new Falla(AGENDA_VENCIDA)
  if (error) throw new Error(`No pude guardar las fechas propuestas: ${error.message}`, { cause: error })
}

/** `Repartir fechas` (decision 25): stores the places the Agenda shows for the unsigned pieces without a live proposal. */
export function repartirFechas(deps: DepsFechas): Promise<Resultado<{ propuestas: number }>> {
  return aResultado("repartirFechas", async () => {
    const ahora = Date.parse(deps.ahora())
    const datos = await leerDatosDeCalendario(deps.db, ahora)
    const nuevos = repartir({ piezas: datos.piezas, horario: datos.horario, ahora }).filter((lugar) => !lugar.guardada)
    if (nuevos.length === 0) return { propuestas: 0 }
    await proponer(
      deps.db,
      nuevos.map((lugar) => lugar.piezaId),
      nuevos.map((lugar) => lugar.instante),
    )
    return { propuestas: nuevos.length }
  })
}

/** `Cambiar` under a proposal: another free slot for that piece (amendment A8). */
export function cambiarPropuesta(deps: DepsFechas, piezaId: string, instante: string): Promise<Resultado> {
  return aResultado("cambiarPropuesta", async () => {
    const ahora = Date.parse(deps.ahora())
    const datos = await leerDatosDeCalendario(deps.db, ahora)
    const pieza = datos.piezas.find((candidata) => candidata.id === piezaId)
    if (!pieza || !sinFechaFirmada(pieza.estado)) throw new Falla(AGENDA_VENCIDA)
    if (!espacioLibreParaCambiar({ piezas: datos.piezas, horario: datos.horario, ahora, piezaId, instante })) {
      throw new Falla(ESPACIO_TOMADO)
    }
    await proponer(deps.db, [piezaId], [new Date(Date.parse(instante)).toISOString()])
    return {}
  })
}
```

```tsx
/**
 * Decision 25: the unsigned pieces without a proposal get the places the Agenda shows them in. Always mounted, so
 * its toast outlives the block once the page refreshes with nothing left to spread.
 */
export function RepartirFechas({
  cuantas,
  repartir,
}: {
  cuantas: number
  repartir: () => Promise<Resultado<{ propuestas: number }>>
}) {
  const [mensaje, setMensaje] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [pendiente, empezar] = useTransition()
  const cerrar = useCallback(() => setMensaje(null), [])

    setError(null)
    empezar(async () => {
      const resultado = await repartir()
      if (!resultado.ok) {
        setError(resultado.error)
        return
      }
      setMensaje(textoDePropuestas(resultado.propuestas))
    })
  }

  return (
    <>

          </Boton>
```
