> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fifth Biblioteca section, `/biblioteca/ganchos`, where Coni reads every hook (the new classified ones and the
92 old free-text ones as «Sin clasificar»), filters them by type, network, pillar, topic, author, favorites and her own
types, and marks favorites.

**Architecture:** One migration adds `ganchos_favoritos`, `ajustes.tipos_de_gancho_preferidos` and the view
`biblioteca_de_ganchos` (security invoker, merges `ganchos` with `afirmaciones.gancho`, derives `pilares` per network
from the topic). The page reads the whole view once (hundreds of rows) and a pure domain module parses the address,
filters and orders in memory, so every rule is unit-tested. Favorites go through a new Server Action; preferred types
go through the existing `guardarAjuste` path with a new `CambioDeAjuste` that keeps only vigente list values. The
screens mirror Autores: table plus sticky side panel (`?g=`) on a computer, cards plus a page of their own on a phone.

**Tech Stack:** Next.js 16 App Router (Server Components + Server Actions), Supabase Postgres (RLS, security-invoker
views), Zod, Tailwind v4 tokens, Vitest (unit with jsdom, integration against local Supabase), Playwright.

Spec: `docs/superpowers/specs/2026-11-26-ganchos-6b-design.md` (authoritative).

## Decisions taken while planning (spec gaps)

1. **Filters run in memory.** The view is read whole (`listarGanchos`, paged by `afirmacion_id`) and
   `filtrarGanchos` applies the address filters. Today there are 92 hooks and a few hundred at most after change 7;
   if they pass a few thousand, move the filters into the query.
2. **`autor_id` in the view is the visible author's id** (`autores_visibles.id`), so an author marked for deletion
   shows no name and no link, while its hooks stay (a marked author never has visible materials anyway).
3. **Retired types keep their label.** `leerVocabulario` drops retired values, so `leerTiposDeGancho` reads the
   vigente `gancho` row with them (`activo: false`). A value absent from the list altogether reads
   «Un tipo que ya no está en la lista».
4. **`ninguno`** (extraction found no type) reads «Ninguno de la lista» and is not a filter option (the spec lists
   only list values plus «Sin clasificar»).
5. **Table columns at 768 to 1023 px:** Frase exacta, Tipo and ★; Autor and Tema join from `lg`, so the table fits
   beside the 20rem panel (the Autores grid `md:grid-cols-[minmax(0,1fr)_20rem]` is kept).
6. **Pillar options** are the active, non-layer pillars of the chosen network (`listarPilaresDeTemas`). A `pilar` in
   the address without its network is dropped.
7. **Saving «Mis tipos»** drops stored types that left the list; the chooser says so before she saves.
8. **`pilares` json** is ordered by network, main pillar first; it has no `principal` flag (not needed by any screen).
9. **The fifth tab changes every Biblioteca desktop baseline**: Batch D regenerates them after checking the diffs.

```sql
-- Change 6b: the hooks library. Adds a table, a column and a view; changes no existing row.

-- Coni's favorite hooks, kept by claim so the same star works for a new hook (`ganchos`) and an old free-text one
-- (`afirmaciones.gancho`). Change 7's reprocess must keep claim ids, or the cascade below drops every favorite.
create table public.ganchos_favoritos (
  afirmacion_id uuid primary key references public.afirmaciones (id) on delete cascade,
  creado_en timestamptz not null default now()
);
alter table public.ganchos_favoritos enable row level security;
revoke all on public.ganchos_favoritos from anon, authenticated;
grant select, insert, delete on public.ganchos_favoritos to authenticated;
grant all on public.ganchos_favoritos to service_role;
create policy "coni y wav leen favoritos de ganchos" on public.ganchos_favoritos for select to authenticated
  using (public.es_coni() or public.es_mantenedor());
create policy "coni marca favoritos de ganchos" on public.ganchos_favoritos for insert to authenticated
  with check (public.es_coni());
create policy "coni quita favoritos de ganchos" on public.ganchos_favoritos for delete to authenticated
  using (public.es_coni());

-- «Mis tipos»: values of the vigente `gancho` list, written through the policy "coni edita ajustes" (guardarAjuste
-- drops anything the list does not have). A value later retired stays stored and the screen ignores it.
alter table public.ajustes add column tipos_de_gancho_preferidos text[] not null default '{}';

-- One row per hook. A claim has at most one row in `ganchos` (unique), and its free text counts only without one,
-- so no claim appears twice. Hidden claims and anything deleted with «Deshacer» stay out: the material through
-- materiales_visibles (inner), the author through autores_visibles (left, its id and name go null). The network comes
-- from the topic's pillars, layers excluded; no topic or no pillar is an empty array («Sin red»).
create view public.biblioteca_de_ganchos with (security_invoker = true) as
select
  a.id as afirmacion_id,
  coalesce(g.frase_exacta, a.gancho) as frase_exacta,
  g.frase_sin_gancho,
  coalesce(g.tipo, 'sin_clasificar') as tipo,
  g.certeza,
  g.id is not null as clasificado,
  coalesce(g.creada_en, a.creada_en) as creado_en,
  a.material_id,
  m.titulo as material_titulo,
  a.ubicacion,
  au.id as autor_id,
  au.nombre as autor_nombre,
  a.tema_id,
  t.nombre as tema_nombre,
  coalesce(
    (select jsonb_agg(
              jsonb_build_object('red', tp.red, 'pilar_id', tp.pilar_id, 'nombre', coalesce(c.nombre_corto, c.nombre))
              order by tp.red, (tp.fuerza = 'alta') desc, c.orden)
       from public.tema_pilares tp
       join public.categorias c on c.id = tp.pilar_id
      where tp.tema_id = a.tema_id and not tp.es_capa),
    '[]'::jsonb
  ) as pilares,
  exists (select 1 from public.ganchos_favoritos f where f.afirmacion_id = a.id) as favorito
from public.afirmaciones a
join public.materiales_visibles m on m.id = a.material_id
left join public.autores_visibles au on au.id = a.autor_id
left join public.ganchos g on g.afirmacion_id = a.id
left join public.temas t on t.id = a.tema_id
where not a.excluida

import type { Red } from "@/lib/dominio/pilares"

import type { Ubicacion } from "./ficha"

/** The two values a hook's type can take outside the list: an old free-text hook, and «no type fits». */
export const SIN_CLASIFICAR = "sin_clasificar"
export const NINGUNO = "ninguno"
export const ETIQUETA_SIN_CLASIFICAR = "Sin clasificar"
const ETIQUETA_NINGUNO = "Ninguno de la lista"
const ETIQUETA_FUERA_DE_LA_LISTA = "Un tipo que ya no está en la lista"

export const AVISO_SIN_CLASIFICAR = "Sin clasificar: el tipo y la frase sin gancho llegan al reprocesar la Biblioteca."
export const SIN_GANCHOS = "Los ganchos aparecen al procesar materiales."
export const SIN_COINCIDENCIAS = "Ningún gancho coincide con esos filtros."

export interface PilarDeGancho {
  red: Red
  pilarId: string
  nombre: string
}

/** A row of `biblioteca_de_ganchos` as the screens use it. */
export interface GanchoDeLista {
  afirmacionId: string
  fraseExacta: string
  /** Null for an old hook: it arrives with change 7's reprocess. */
  fraseSinGancho: string | null
  /** A list value, `ninguno`, or `sin_clasificar` for an old hook. */
  tipo: string
  certeza: Certeza | null
  clasificado: boolean
  creadoEn: string
  material: { id: string; titulo: string | null }
  ubicacion: Ubicacion | null
  autor: { id: string; nombre: string } | null
  tema: { id: string; nombre: string } | null
  /** Per network, from the topic's pillars (layers excluded); empty is «Sin red». */
  pilares: PilarDeGancho[]
  favorito: boolean
}

/** A value of the vigente `gancho` list; a retired one stays for the hooks and choices that carry it. */
export interface TipoDeGancho {
  valor: string
  etiqueta: string
  activo: boolean
}

export interface Opcion {
  id: string
  nombre: string
}

export function tiposDeGancho(valores: readonly ValorGuardado[]): TipoDeGancho[] {
  return valores.map((valor) => ({ valor: valor.valor, etiqueta: valor.etiqueta, activo: !valor.retirado }))
}

export function etiquetaDeTipo(tipos: readonly TipoDeGancho[], valor: string): string {
  if (valor === SIN_CLASIFICAR) return ETIQUETA_SIN_CLASIFICAR
  if (valor === NINGUNO) return ETIQUETA_NINGUNO
  return tipos.find((tipo) => tipo.valor === valor)?.etiqueta ?? ETIQUETA_FUERA_DE_LA_LISTA
}

/** Her chosen types that still filter: a type retired from the list stays stored and is ignored. */
export function tiposPreferidosActivos(preferidos: readonly string[], tipos: readonly TipoDeGancho[]): string[] {
  return preferidos.filter((valor) => tipos.some((tipo) => tipo.valor === valor && tipo.activo))
}

/** What «Mis tipos» may store: the vigente values asked for, once each, in the list's order. */
export function tiposDeGanchoValidos(vocab: Vocabulario, valores: readonly string[]): string[] {
  const pedidos = new Set(valores)
  return vocab.gancho.todas.valores.map((valor) => valor.valor).filter((valor) => pedidos.has(valor))
}

/** Favorites first, then the newest (spec 6b); the id breaks ties so the order never jumps between renders. */
export function ordenarGanchos<T extends Pick<GanchoDeLista, "afirmacionId" | "creadoEn" | "favorito">>(
  ganchos: readonly T[],
): T[] {
  return ganchos.toSorted(
    (a, b) =>
      Number(b.favorito) - Number(a.favorito) ||
      Date.parse(b.creadoEn) - Date.parse(a.creadoEn) ||
      a.afirmacionId.localeCompare(b.afirmacionId),
  )
}

function distintas(opciones: readonly (Opcion | null)[]): Opcion[] {
  const porId = new Map<string, Opcion>()
  for (const opcion of opciones) if (opcion) porId.set(opcion.id, opcion)
  return [...porId.values()].sort((a, b) => a.nombre.localeCompare(b.nombre, "es"))
}

/** The authors and topics the filters offer: only those that have a hook. */
export function opcionesDeFiltros(ganchos: readonly GanchoDeLista[]): { autores: Opcion[]; temas: Opcion[] } {
  return {
    autores: distintas(ganchos.map((gancho) => gancho.autor)),
    temas: distintas(ganchos.map((gancho) => gancho.tema)),
  }
}

export const RUTA_DE_GANCHOS = "/biblioteca/ganchos"
export const hrefDeGancho = (id: string) => `${RUTA_DE_GANCHOS}/${id}`

export const SIN_RED = "sin_red"
export type RedDeFiltro = Red | typeof SIN_RED

/**
 * Coni's filters of the hooks (spec 6b). Every value lives in the address. A switch is present only when on, so two
 * equal choices are equal objects. `pilar` exists only with `red` set to a network.
 */
export interface FiltrosDeGanchos {
  tipo?: string
  red?: RedDeFiltro
  pilar?: string
  tema?: string
  autor?: string
  favoritos?: true
  misTipos?: true
}

export interface ContextoDeGanchos {
  tipos: readonly TipoDeGancho[]
  pilares: readonly PilarDeRed[]
  /** Her preferred types still active in the list (`tiposPreferidosActivos`). */
  misTipos: readonly string[]
}

type Params = Record<string, string | string[] | undefined>

const ENCENDIDO = "1"
const VALOR_DE_LISTA = /^[a-z_]{1,60}$/

const primero = (valor: string | string[] | undefined) => (Array.isArray(valor) ? valor[0] : valor)?.trim()

function uuid(valor: string | string[] | undefined): string | undefined {
  const leido = z.uuid().safeParse(primero(valor))
  return leido.success ? leido.data : undefined
}

/** The address read on its own, without the lists: what the filter form sends. Invalid values read as absent. */
export function filtrosDeParametros(params: Params): FiltrosDeGanchos {
  const filtros: FiltrosDeGanchos = {}
  const tipo = primero(params.tipo)
  if (tipo && VALOR_DE_LISTA.test(tipo)) filtros.tipo = tipo
  const red = primero(params.red)
  if (esRed(red) || red === SIN_RED) filtros.red = red
  const pilar = uuid(params.pilar)
  if (pilar && esRed(filtros.red)) filtros.pilar = pilar
  const tema = uuid(params.tema)
  if (tema) filtros.tema = tema
  const autor = uuid(params.autor)
  if (autor) filtros.autor = autor
  if (primero(params.favoritos) === ENCENDIDO) filtros.favoritos = true
  if (primero(params["mis-tipos"]) === ENCENDIDO) filtros.misTipos = true
  return filtros
}

/** Against the lists: an active type or «Sin clasificar», a pillar of the chosen network, «Mis tipos» only if any. */
export function validarFiltros(filtros: FiltrosDeGanchos, contexto: ContextoDeGanchos): FiltrosDeGanchos {
  const { tipo, pilar, misTipos, ...resto } = filtros
  const validos: FiltrosDeGanchos = { ...resto }
  if (tipo && (tipo === SIN_CLASIFICAR || contexto.tipos.some((t) => t.valor === tipo && t.activo))) validos.tipo = tipo
  if (pilar && contexto.pilares.some((p) => p.id === pilar && p.red === filtros.red && !p.esCapa)) validos.pilar = pilar
  if (misTipos && contexto.misTipos.length > 0) validos.misTipos = true
  return validos
}

export function leerFiltrosDeGanchos(params: Params, contexto: ContextoDeGanchos): FiltrosDeGanchos {
  return validarFiltros(filtrosDeParametros(params), contexto)
}

const ORDEN = ["tipo", "red", "pilar", "tema", "autor"] as const

/** The list's address with these filters (and the side panel open on `seleccion`): linkable, Back undoes it. */
export function hrefDeGanchos(filtros: FiltrosDeGanchos, seleccion: string | null = null): string {
  const params = new URLSearchParams()
  for (const clave of ORDEN) {
    const valor = filtros[clave]
    if (valor) params.set(clave, valor)
  }
  if (filtros.favoritos) params.set("favoritos", ENCENDIDO)
  if (filtros.misTipos) params.set("mis-tipos", ENCENDIDO)
  if (seleccion) params.set("g", seleccion)
  const consulta = params.toString()
  return consulta ? `${RUTA_DE_GANCHOS}?${consulta}` : RUTA_DE_GANCHOS
}

/** The cascade: a pillar belongs to one network, so changing or clearing the network clears it. */
export function conRed(filtros: FiltrosDeGanchos, red: RedDeFiltro | undefined): FiltrosDeGanchos {
  const { red: _red, pilar: _pilar, ...resto } = filtros
  return red ? { ...resto, red } : resto
}

export function conPilar(filtros: FiltrosDeGanchos, pilar: string | undefined): FiltrosDeGanchos {
  const { pilar: _pilar, ...resto } = filtros
  return pilar ? { ...resto, pilar } : resto
}

export function alternarFavoritos(filtros: FiltrosDeGanchos): FiltrosDeGanchos {
  const { favoritos, ...resto } = filtros
  return favoritos ? resto : { ...resto, favoritos: true }
}

export function alternarMisTipos(filtros: FiltrosDeGanchos): FiltrosDeGanchos {
  const { misTipos, ...resto } = filtros
  return misTipos ? resto : { ...resto, misTipos: true }
}

/** Type, topic and author live folded under «Más filtros». */
export function filtrosPlegados(filtros: FiltrosDeGanchos): number {
  return [filtros.tipo, filtros.tema, filtros.autor].filter(Boolean).length
}

export function sinPlegados(filtros: FiltrosDeGanchos): FiltrosDeGanchos {
  const { tipo: _tipo, tema: _tema, autor: _autor, ...resto } = filtros
  return resto
}

export function hayFiltrosDeGanchos(filtros: FiltrosDeGanchos): boolean {
  return Object.keys(filtros).length > 0
}

/** The hooks that pass every filter; `misTipos` are her active preferred types. */
export function filtrarGanchos<T extends GanchoDeLista>(
  ganchos: readonly T[],
  filtros: FiltrosDeGanchos,
  misTipos: readonly string[],
): T[] {
  return ganchos.filter(
    (gancho) =>
      (!filtros.tipo || gancho.tipo === filtros.tipo) &&
      (!filtros.red ||
        (filtros.red === SIN_RED
          ? gancho.pilares.length === 0
          : gancho.pilares.some((pilar) => pilar.red === filtros.red))) &&
      (!filtros.pilar || gancho.pilares.some((pilar) => pilar.pilarId === filtros.pilar)) &&
      (!filtros.tema || gancho.tema?.id === filtros.tema) &&
      (!filtros.autor || gancho.autor?.id === filtros.autor) &&
      (!filtros.favoritos || gancho.favorito) &&
      (!filtros.misTipos || misTipos.includes(gancho.tipo)),
  )
}

    const consulta = db.from("biblioteca_de_ganchos").select(COLUMNAS)
    return (despuesDe === null ? consulta : consulta.gt("afirmacion_id", despuesDe))

      .then(({ data, error }) => ({

        error,
      }))

    .eq("afirmacion_id", afirmacionId)

export const CambioDeFavorito = z.object({ afirmacionId: z.uuid(), favorito: z.boolean() })
export const GANCHO_INEXISTENTE = "Ese gancho ya no está en la Biblioteca."

const SIN_AFIRMACION = "23503"

/**
 * The star of a hook (spec 6b), kept by claim so it holds for new and old hooks alike. Marking what is already marked,
 * or unmarking what is not, changes nothing and is not an error: two taps in two tabs agree.
 */
export function marcarFavorito(deps: { db: Db }, cambio: z.output<typeof CambioDeFavorito>): Promise<Resultado> {
  return aResultado("marcarFavorito", async () => {
    await exigirConi(deps.db)
    const { error } = cambio.favorito
      ? await deps.db
          .from("ganchos_favoritos")
          .upsert({ afirmacion_id: cambio.afirmacionId }, { onConflict: "afirmacion_id", ignoreDuplicates: true })
      : await deps.db.from("ganchos_favoritos").delete().eq("afirmacion_id", cambio.afirmacionId)
    if (error?.code === SIN_AFIRMACION) throw new Falla(GANCHO_INEXISTENTE)
    if (error) throw new Error(`No pude cambiar el favorito ${cambio.afirmacionId}: ${error.message}`, { cause: error })
    return {}
  })
}
```

/** The parts of a hook and where it comes from (spec 6b), shared by the side panel and the phone's page. */
export function DetalleDeGancho({ gancho, tipos }: { gancho: GanchoDeLista; tipos: readonly TipoDeGancho[] }) {
  const donde = gancho.ubicacion ? textoDeUbicacion(gancho.ubicacion) : null
  const redes = REDES.flatMap((red) => {

"use client"

import { SlidersHorizontal } from "@phosphor-icons/react"
import { useState } from "react"
import { Boton } from "@/components/ui/boton"
import { Casilla } from "@/components/ui/casilla"
import { ICONO } from "@/components/ui/icono"
import { LineaDeError } from "@/components/ui/linea-de-error"
import { MasOpciones } from "@/components/ui/mas-opciones"
import { useAccion } from "@/components/use-accion"
import { etiquetaDeTipo, type TipoDeGancho } from "@/lib/dominio/biblioteca/ganchos"
import { guardarMisTiposAccion } from "../acciones"

/**
 * «Mis tipos» (spec 6b): the active types as boxes; saving stores them in Ajustes. The «Mis tipos» filter appears once
 * at least one is saved. A chosen type that left the list is named here, since saving drops it.
 */
export function ElegirMisTipos({ tipos, elegidos }: { tipos: readonly TipoDeGancho[]; elegidos: readonly string[] }) {
  const activos = tipos.filter((tipo) => tipo.activo)
  const esActivo = (valor: string) => activos.some((tipo) => tipo.valor === valor)
  const [marcados, setMarcados] = useState<string[]>(() => elegidos.filter(esActivo))
  const [guardado, setGuardado] = useState(false)
  const { pendiente, error, ejecutar } = useAccion()
  const retirados = elegidos.filter((valor) => !esActivo(valor))

  function alternar(valor: string, marcada: boolean) {
    setGuardado(false)
    setMarcados((actuales) => (marcada ? [...actuales, valor] : actuales.filter((otro) => otro !== valor)))
  }

  return (
    <MasOpciones
      titulo="Elegir mis tipos"
      forma="boton"
      icono={<SlidersHorizontal aria-hidden="true" size={ICONO.chico} />}
      className="open:basis-full [&>summary]:w-fit [&>summary]:gap-2 [&>summary]:px-4 [&>summary]:text-meta"
    >
      <div className="grid gap-3 md:max-w-xl">
        <fieldset className="m-0 grid min-w-0 border-0 p-0 md:grid-cols-2 md:gap-x-6">
          <legend className="mb-1 text-cuerpo font-semibold">Mis tipos de gancho</legend>
          {activos.map((tipo) => (
            <Casilla
              key={tipo.valor}
              etiqueta={tipo.etiqueta}
              marcada={marcados.includes(tipo.valor)}
              alCambiar={(marcada) => alternar(tipo.valor, marcada)}
            />
          ))}
        </fieldset>
        {retirados.length > 0 ? (
          <p className="text-meta text-apagado">
            {`Ya no están en la lista y se quitan al guardar: ${retirados.map((valor) => etiquetaDeTipo(tipos, valor)).join(", ")}.`}
          </p>
        ) : null}
        <Boton
          variante="secundario"
          tamano="chico"
          className="w-fit"
          cargando={pendiente}
          onClick={() => ejecutar(() => guardarMisTiposAccion(marcados), () => setGuardado(true))}
        >
          Guardar mis tipos
        </Boton>
        <output aria-live="polite" className="text-meta text-apagado empty:sr-only">
          {guardado ? "Guardé tus tipos." : ""}
        </output>
        {error ? <LineaDeError>{error}</LineaDeError> : null}
      </div>
    </MasOpciones>
  )
}

export async function sembrarGanchos(): Promise<EscenaDeGanchos> {
  const idea = (texto: string) => uno("select id from public.afirmaciones where texto = $1", [texto])
  const linkedin = await idea(GANCHO_LINKEDIN.frase)

    `insert into public.ganchos (afirmacion_id, frase_exacta, frase_sin_gancho, tipo, certeza, version_id, origen, creada_en)
     select f.id, f.frase, f.sin_gancho, f.tipo, 'alta', v.id, 'extraccion', now() - f.hace::interval
       from (values ($1::uuid, $2::text, $3::text, 'verdad_incomoda', '2 hours'),
                    ($4::uuid, $5::text, $6::text, 'escena', '1 hour')) as f (id, frase, sin_gancho, tipo, hace)
       cross join public.versiones_de_vocabulario v
      where v.lista = 'gancho' and v.estado = 'vigente'`,

      linkedin,
      GANCHO_LINKEDIN.frase,
      GANCHO_LINKEDIN.sinGancho,
      instagram,
      GANCHO_INSTAGRAM.frase,
      GANCHO_INSTAGRAM.sinGancho,
    ],
  )
  await pool.query("update public.afirmaciones set gancho = $1 where id = $2", [GANCHO_ANTIGUO, antiguo])
