# voyage-4 embeddings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Conidolly's knowledge base from voyage-3.5 to voyage-4 only after a dry run in parallel tables shows what would change, apply it in one transaction after Federico's explicit OK, and keep a 30-day way back. Topic assignments never change on the switch.

**Architecture:** The model and the five similarity thresholds become data: one vigente row of `calibraciones_de_parecido`. Every vector and centroid is stamped with its model; two `before` triggers keep the stamps honest and drop or refuse writes made with a model that stopped being vigente. A pure module (`lib/dominio/parecido.ts`) moves each threshold to the new model by percentile transfer and builds the Spanish report. Three manual Trigger.dev tasks on the maintenance queue (`probar-`, `aplicar-`, `revertir-modelo-de-huellas`) embed through `gastos`, respect a Voyage pause and call two `security definer` RPCs that swap everything in one transaction.

**Tech Stack:** Next.js 16 / TypeScript strict, Supabase Postgres 17 + pgvector (`vector(1024)`, `extensions.avg`, `<#>`, `<=>`), Trigger.dev v4 (`schemaTask`, shared `queue`), Voyage embeddings API (`output_dimension`), zod, Vitest (unit + integration against local Supabase), msw.

**Spec:** `docs/superpowers/specs/2026-11-09-voyage-4-design.md` (issue #19, change 17, B1 in `docs/pedido-coni-2026-10-31/decisiones.md`).

## Decisions taken in this plan (and deviations from the spec)

1. **The model lives only in the calibration row, not in `ajustes`.** Spec: `ajustes.modelo_de_huellas`. Plan: `calibraciones_de_parecido.modelo` of the vigente row is the one model; `leerCalibracion(db)` returns it with the thresholds. Why: one source of truth that the switch changes in one row, and `ajustes` is writable by Coni's session (table-wide RLS update policy), so a model column there could be changed from the app.
2. **Stamps are enforced by two triggers, not by editing each SQL writer.** `sellar_modelo_de_vector` (afirmaciones) stamps an unstamped vector with the vigente model and drops a vector stamped with another model (maintenance embeds it again). `sellar_modelo_de_centroide` (temas) stamps SQL recomputations with the vigente model and refuses a TypeScript write that names a stale model (`modelo_de_huellas_cambio`). Why: `recalcular_tema`, `fusionar_par_de_temas`, `reprocesar_material` and 20261109000100 need no redefinition; the Trigger code deployed before this change keeps working between `db push` and the Trigger deploy; and a material processed while the switch runs cannot leave a voyage-3.5 vector in a voyage-4 base.
3. **No `aplicando` state and no flag in maintenance.** The three tasks run on `COLA_DE_MANTENIMIENTO` (concurrency 1), so `mantenimiento-frecuente` and `-nocturno` never run during a dry run, apply or revert. Ingestion (its own queue) is covered by the table locks inside the RPC plus decision 2. Why: a flag left in `aplicando` by a crashed run would stop topics forever.
4. **`huellas_candidatas` holds claims only.** The apply RPC recomputes every centroid in SQL as the plain mean of the new vectors (same invariant as 20261003000351), so it also covers claims assigned after the dry run; a merged topic takes the centroid of the topic it points at. Candidate centroids are computed in memory for the report only.
5. **No `scripts/modelo/revertir.ts`.** The way back is the `revertir-modelo-de-huellas` Trigger task, run from the dashboard «Test» button or the Trigger MCP. Why: the script would need a Trigger secret key on a laptop; the task already keeps every secret inside Trigger.
6. **One reservation per Voyage request (128 texts), not one per run.** It reuses `pagarPaso` as every other embed does; 209 claims are 2 requests.
7. **Extra columns:** `pruebas_de_modelo.version_anterior` (the calibration the apply replaced, read by the revert) and `calibraciones_de_parecido.prueba_id` (which dry run created the row; the revert refuses unless it is the vigente one).
8. **The apply returns a fingerprint of all assignments before and after** (`md5` of `id:tema_id` in id order, inside the transaction), so "no topic assignment changed" is proven by the run, not by a later query.
9. **`HOLGURA_DEL_PUENTE` stays 0.15.** It is not a threshold in the spec's table; flagged to Federico in case voyage-4 compresses the similarity range.
10. **Staging uses the real Voyage API.** Federico adds `VOYAGE_API_KEY` (the production key) to the Trigger Staging environment; the seed has 7 claims, and Claude adds 13 synthetic claims (generic sentences written in Task 16, not Coni's content) and synthetic voyage-3.5 vectors so the mechanics have something to move. Cost: a few hundred tokens, inside the 200M free tokens. Why not a fake: only a real call confirms voyage-4 answers 1024 dimensions with `output_dimension`.
11. **Excluded claims with a vector are re-embedded too** (every claim with a vector gets a candidate), so un-excluding one later never brings an old vector back; they are left out of the percentile samples and the report.

## Percentile transfer, per threshold

`trasladarPorPercentil(viejos, nuevos, umbral)` (pure, deterministic):

1. Sort both samples ascending: `v` (old model, n values) and `w` (new model, m values); both need at least 2.
2. If `umbral <= v[0]`, return `w[0] - (v[0] - umbral)`. If `umbral >= v[n-1]`, return `w[m-1] + (umbral - v[n-1])` (outside the observed range the threshold keeps its distance to the nearest extreme).
3. Otherwise find the last `i` with `v[i] <= umbral`; the fractional rank is `r = (i + (umbral - v[i]) / (v[i+1] - v[i])) / (n - 1)`.
4. Read `w` at the same fractional rank with linear interpolation: `p = r * (m - 1)`, `j = floor(p)`, result `w[j] + (p - j) * (w[j+1] - w[j])`.
5. `calcularUmbrales` clamps to [0, 1] and rounds to 4 decimals.

Identical samples return the threshold; a sample shifted by `d` returns the threshold plus `d`.

| Threshold | Sample (old vs new, paired) | Why |
|---|---|---|
| `tema` | every non-excluded claim with a vector × every active topic: `v · centroide` (old: stored centroid; new: mean of the new vectors of its claims). Production: 209 × 15 = 3135. | exactly what `tema_mas_cercano` scores |
| `grupo` | every pair of non-excluded claims with a vector: `v_i · v_j`. Production: 21,736. | `agruparPorSimilitud` scores the mean of these pairwise cosines |
| `fusion`, `puente_min`, `puente_max` | every pair of active topics: `m_A · m_B`. Production: 105. | `temas_parecidos` and `motor_pares` use this inner product |

Fallback: when a sample has fewer than `MINIMO_DE_MUESTRAS = 20` values (fewer than 7 topics for topic pairs, fewer than 20 claim-topic pairs), the threshold is transferred with the claim-pair sample instead (`m_A · m_B` is itself a mean of claim-pair cosines). When the claim-pair sample has fewer than 20 values (fewer than 7 claims), the dry run fails with `MuestraInsuficiente` and writes nothing. The report names the sample and its size for every threshold.

```ts
/**
 * Similarity under an embedding model: which models exist, the five thresholds that belong to each one and how a
 * threshold moves from one model to another (spec 2026-11-09-voyage-4-design.md). Pure.
 */

/** The embedding models Conidolly can run. Vectors of one are never compared with vectors of the other. */
export const MODELOS_DE_HUELLAS = ["voyage-3.5", "voyage-4"] as const
export type ModeloDeHuellas = (typeof MODELOS_DE_HUELLAS)[number]

/** All on the mean-cosine scale of docs/superpowers/notas/calibracion-c1.md. */
export type Umbrales = {
  /** A claim joins a topic (`tema_mas_cercano`). */
  tema: number
  /** Pending claims group into a new topic (`agruparPorSimilitud`). */
  grupo: number
  /** Two topics are candidates to merge (`temas_parecidos`). */
  fusion: number
  /** The engine's bridge band between two topics (`puntuarPar`). */
  puenteMin: number
  puenteMax: number
}

export type Calibracion = Umbrales & { version: number; modelo: ModeloDeHuellas }

/** Version 1, seeded by 20261111000100: the values measured for voyage-3.5 in calibracion-c1.md. */
export const CALIBRACION_INICIAL: Calibracion = {
  version: 1,
  modelo: "voyage-3.5",
  tema: 0.8,
  grupo: 0.8,
  fusion: 0.8,
  puenteMin: 0.6,
  puenteMax: 0.8,
}

const ascendente = (valores: readonly number[]): number[] => [...valores].sort((a, b) => a - b)

/**
 * The new-model value that sits at the same empirical quantile `umbral` has among the old-model values. Inside the
 * old range the rank is interpolated linearly between neighbours; outside it the threshold keeps its distance to the
 * nearest extreme. Identical samples return `umbral`; a sample shifted by d returns `umbral + d`.
 */
export function trasladarPorPercentil(viejos: readonly number[], nuevos: readonly number[], umbral: number): number {
  if (viejos.length < 2 || nuevos.length < 2) throw new Error("Hacen falta al menos dos muestras de cada modelo.")
  const v = ascendente(viejos)
  const w = ascendente(nuevos)
  const primeroV = v[0] ?? 0
  const ultimoV = v[v.length - 1] ?? 0
  const primeroW = w[0] ?? 0
  const ultimoW = w[w.length - 1] ?? 0
  if (umbral <= primeroV) return primeroW - (primeroV - umbral)
  if (umbral >= ultimoV) return ultimoW + (umbral - ultimoV)
  let i = 0
  while ((v[i + 1] ?? Number.POSITIVE_INFINITY) <= umbral) i++
  const abajo = v[i] ?? primeroV
  const arriba = v[i + 1] ?? ultimoV
  const rango = (i + (umbral - abajo) / (arriba - abajo)) / (v.length - 1)
  const posicion = rango * (w.length - 1)
  const j = Math.floor(posicion)
  const desde = w[j] ?? ultimoW
  const hasta = w[j + 1] ?? desde
  return desde + (posicion - j) * (hasta - desde)
}
```

```ts
export const MINIMO_DE_MUESTRAS = 20

export class MuestraInsuficiente extends Error {
  constructor(n: number) {
    super(`Hay ${n} pares de afirmaciones con vector; hacen falta ${MINIMO_DE_MUESTRAS} para calibrar.`)
    this.name = "MuestraInsuficiente"
  }

/** A claim with its vector under the vigente model and under the model being tried. */
export type AfirmacionParaPrueba = {
  id: string
  texto: string
  temaId: string | null
  excluida: boolean
  viejo: number[]
  nuevo: number[]
}

/** A topic with its stored (vigente-model) centroid. */
export type TemaParaPrueba = { id: string; nombre: string; fusionadoEn: string | null; viejo: number[] }

export type FuenteDeMuestras = "afirmacion_afirmacion" | "afirmacion_tema" | "tema_tema"
export type ParDeMuestras = { viejos: number[]; nuevos: number[] }
export type Muestras = Record<FuenteDeMuestras, ParDeMuestras>

export type UmbralTrasladado = { viejo: number; nuevo: number; fuente: FuenteDeMuestras; muestras: number }
export type Traslado = Record<keyof Umbrales, UmbralTrasladado>

/** Inner product: what pgvector's `<#>` negates. For unit vectors it is the cosine. */
export function punto(a: readonly number[], b: readonly number[]): number {
  let suma = 0
  for (let i = 0; i < a.length; i++) suma += (a[i] ?? 0) * (b[i] ?? 0)
  return suma
}

/**
 * The centroids the switch would write, by the rules of `aplicar_prueba_de_modelo`: the plain mean of the new vectors
 * of a topic's claims; a merged topic, the centroid of the topic it points at. An active topic none of whose claims has
 * a vector gets none (the report lists it and the switch refuses it).
 */
export function centroidesNuevos(
  temas: readonly TemaParaPrueba[],
  afirmaciones: readonly AfirmacionParaPrueba[],
): Map<string, number[]> {
  const centroides = new Map<string, number[]>()
  for (const tema of temas) {
    if (tema.fusionadoEn) continue
    const vectores = afirmaciones.filter((a) => a.temaId === tema.id && !a.excluida).map((a) => a.nuevo)
    if (vectores.length > 0) centroides.set(tema.id, media(vectores))
  }
  for (const tema of temas) {
    const destino = tema.fusionadoEn ? centroides.get(tema.fusionadoEn) : undefined
    if (destino) centroides.set(tema.id, destino)
  }
  return centroides
}

const vacio = (): ParDeMuestras => ({ viejos: [], nuevos: [] })

/** The paired samples of section «Percentile transfer, per threshold» of the plan, over non-excluded claims and active topics. */
export function muestrasDeParecido(
  afirmaciones: readonly AfirmacionParaPrueba[],
  temas: readonly TemaParaPrueba[],
  nuevos: ReadonlyMap<string, readonly number[]>,
): Muestras {
  const vivas = afirmaciones.filter((a) => !a.excluida)
  const activos = temas.flatMap((t) => {
    const nuevo = nuevos.get(t.id)
    return !t.fusionadoEn && nuevo ? [{ viejo: t.viejo, nuevo }] : []
  })
  const muestras: Muestras = { afirmacion_afirmacion: vacio(), afirmacion_tema: vacio(), tema_tema: vacio() }
  for (const [i, a] of vivas.entries()) {
    for (const b of vivas.slice(i + 1)) {
      muestras.afirmacion_afirmacion.viejos.push(punto(a.viejo, b.viejo))
      muestras.afirmacion_afirmacion.nuevos.push(punto(a.nuevo, b.nuevo))
    }
    for (const t of activos) {
      muestras.afirmacion_tema.viejos.push(punto(a.viejo, t.viejo))
      muestras.afirmacion_tema.nuevos.push(punto(a.nuevo, t.nuevo))
    }
  }
  for (const [i, x] of activos.entries()) {
    for (const y of activos.slice(i + 1)) {
      muestras.tema_tema.viejos.push(punto(x.viejo, y.viejo))
      muestras.tema_tema.nuevos.push(punto(x.nuevo, y.nuevo))
    }
  }
  return muestras
}

const acotar = (x: number): number => Math.round(Math.min(1, Math.max(0, x)) * 10_000) / 10_000

/** Each threshold moved by percentile over the sample that matches its use, or over the claim pairs when that one is small. */
export function calcularUmbrales(muestras: Muestras, vigentes: Umbrales): Traslado {
  const base = muestras.afirmacion_afirmacion
  if (base.viejos.length < MINIMO_DE_MUESTRAS) throw new MuestraInsuficiente(base.viejos.length)
  const trasladar = (clave: keyof Umbrales, preferida: FuenteDeMuestras): UmbralTrasladado => {
    const fuente = muestras[preferida].viejos.length >= MINIMO_DE_MUESTRAS ? preferida : "afirmacion_afirmacion"
    const par = muestras[fuente]
    const viejo = vigentes[clave]
    return { viejo, nuevo: acotar(trasladarPorPercentil(par.viejos, par.nuevos, viejo)), fuente, muestras: par.viejos.length }
  }
  return {
    tema: trasladar("tema", "afirmacion_tema"),
    grupo: trasladar("grupo", "afirmacion_afirmacion"),
    fusion: trasladar("fusion", "tema_tema"),
    puenteMin: trasladar("puenteMin", "tema_tema"),
    puenteMax: trasladar("puenteMax", "tema_tema"),
  }
}

export function umbralesDe(traslado: Traslado): Umbrales {
  return {
    tema: traslado.tema.nuevo,
    grupo: traslado.grupo.nuevo,
    fusion: traslado.fusion.nuevo,
    puenteMin: traslado.puenteMin.nuevo,
    puenteMax: traslado.puenteMax.nuevo,
  }
}

/**
 * Mirror of `tema_mas_cercano` (20261016000100): the 10 closest topics by cosine, then the best inner product (ties by
 * id) if it reaches `umbral`.
 */
export function temaMasCercano(
  v: readonly number[],
  centroides: ReadonlyMap<string, readonly number[]>,
  umbral: number,
): { temaId: string; parecido: number } | null {
  const [mejor] = [...centroides]
    .map(([temaId, c]) => ({ temaId, distancia: 1 - coseno(v, c), parecido: punto(v, c) }))
    .sort((a, b) => a.distancia - b.distancia)
    .slice(0, 10)
    .filter((c) => c.parecido >= umbral)
    .sort((a, b) => b.parecido - a.parecido || (a.temaId < b.temaId ? -1 : 1))
  return mejor ? { temaId: mejor.temaId, parecido: mejor.parecido } : null
}
```

```ts
  const cambiosDeCercano = vivas.flatMap((a) => {
    if (a.temaId === null) return []
    const antes = temaMasCercano(a.viejo, viejos, Number.NEGATIVE_INFINITY)
    const despues = temaMasCercano(a.nuevo, nuevos, Number.NEGATIVE_INFINITY)
    if (!antes || !despues || antes.temaId === despues.temaId) return []
    return [{ texto: recortar(a.texto), de: nombre.get(antes.temaId) ?? antes.temaId, a: nombre.get(despues.temaId) ?? despues.temaId }]
  })
  return {
    modelo: e.modelo,
    modeloAnterior: e.vigente.modelo,
    umbrales: e.traslado,
    afirmaciones: vivas.length,
    temas: activos.length,
    temasSinCentroide: activos.filter((t) => !nuevos.has(t.id)).map((t) => t.nombre),
    fusiones,
    nuevasAsignaciones: { total: nuevas.length, muestra: nuevas.slice(0, MUESTRA_DE_ASIGNACIONES) },
    cambiosDeCercano,
    costoUsd: e.costoUsd,
  }
}

  }

  else {

    for (const f of i.fusiones) lineas.push(`- «${f.a}» y «${f.b}» se juntarían (${decimal(f.parecido)}).`)
  }
  lineas.push("")
  if (i.nuevasAsignaciones.total === 0) lineas.push("Ninguna afirmación sin tema encontraría uno.")
  else {
    lineas.push(`Afirmaciones sin tema que encontrarían uno: ${i.nuevasAsignaciones.total}. Por ejemplo:`)
    for (const m of i.nuevasAsignaciones.muestra) lineas.push(`- «${m.texto}» → ${m.tema}`)
  }
  lineas.push("")
  if (i.cambiosDeCercano.length === 0) lineas.push("Ninguna afirmación con tema cambia de tema más cercano.")
  else {
    lineas.push(`Afirmaciones con tema cuyo tema más cercano cambia: ${i.cambiosDeCercano.length} (siguen en su tema: el cambio no mueve asignaciones).`)
    for (const c of i.cambiosDeCercano) lineas.push(`- «${c.texto}»: ${c.de} → ${c.a}`)
  }
  lineas.push("")
  lineas.push(
    i.temasSinCentroide.length === 0
      ? "Todos los temas tienen centroide con el modelo nuevo."
      : `Temas sin centroide con el modelo nuevo (el cambio se niega mientras existan): ${i.temasSinCentroide.join(", ")}.`,
  )
  lineas.push(`Costo de la prueba: US$ ${decimal(i.costoUsd, 4)}.`)
  return lineas.join("\n")
}
```

```ts
export function vec(componentes: Record<number, number>): number[] {
  const v = Array.from({ length: 1024 }, () => 0)
```

```sql
-- A vector written without a model (the Trigger code deployed before this migration, SQL) takes the vigente one. A
-- vector stamped with another model was embedded before a switch committed: it is dropped, and maintenance embeds the
-- claim again with the vigente model.
create function public.sellar_modelo_de_vector() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  actual text := public.modelo_de_huellas_vigente();
begin
  if new.vector is null then
    new.modelo_vector := null;
  elsif new.modelo_vector is null then
    new.modelo_vector := actual;
  elsif new.modelo_vector <> actual then
    new.vector := null;
    new.modelo_vector := null;
  end if;
  return new;
end $$;
```

```sql
-- The switch and the way back of a model dry run (issue 19). One transaction each: nothing is ever half written.
-- Topic assignments are never touched; each call returns a fingerprint of them before and after, as proof.

create function public.huella_de_asignaciones() returns text
language sql stable set search_path = '' as $$
  select md5(coalesce(string_agg(a.id::text || ':' || coalesce(a.tema_id::text, '-'), ',' order by a.id), ''))
  from public.afirmaciones a
$$;

-- Claims with a vector that still lack their row for a dry run: candidates (before the switch) or saved vectors
-- (before the way back). The tasks embed them and insert the rows, then call the switch.
create function public.afirmaciones_sin_huella(p_prueba uuid, p_destino text)
returns table (id uuid, texto text)
language sql stable security definer set search_path = '' as $$
  select a.id, a.texto
  from public.afirmaciones a
  where a.vector is not null
    and case p_destino
      when 'candidata' then not exists (
        select 1 from public.huellas_candidatas h where h.prueba_id = p_prueba and h.afirmacion_id = a.id)
      when 'anterior' then not exists (
        select 1 from public.huellas_anteriores h where h.prueba_id = p_prueba and h.afirmacion_id = a.id)
    end
  order by a.id
$$;

create function public.aplicar_prueba_de_modelo(p_prueba uuid) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  prueba public.pruebas_de_modelo;
  anterior public.calibraciones_de_parecido;
  nueva int;
  antes text;
begin
  select * into prueba from public.pruebas_de_modelo where id = p_prueba for update;
  if not found then
    raise exception using errcode = 'P0002', message = 'prueba_inexistente';
  end if;
  if prueba.estado <> 'lista' then
    raise exception using errcode = '22023', message = 'prueba_no_lista';
  end if;
  if prueba.creada_en < now() - interval '30 days' then
    raise exception using errcode = '22023', message = 'prueba_vencida';
  end if;
  select * into anterior from public.calibraciones_de_parecido where vigente for update;
  if anterior.modelo = prueba.modelo then
    raise exception using errcode = '22023', message = 'modelo_ya_vigente';
  end if;
  -- Writers of vectors and centroids wait for this transaction; what they computed with the old model is dropped
  -- (claims) or refused (topics) by the stamp triggers once it commits.
  lock table public.afirmaciones, public.temas in share row exclusive mode;
  if exists (
    select 1 from public.afirmaciones a
    where a.vector is not null
      and not exists (select 1 from public.huellas_candidatas h where h.prueba_id = p_prueba and h.afirmacion_id = a.id)
  ) then
    raise exception using errcode = '22023', message = 'faltan_candidatas';
  end if;
  antes := public.huella_de_asignaciones();

  insert into public.huellas_anteriores (prueba_id, afirmacion_id, modelo, vector, version_calibracion)
  select p_prueba, a.id, a.modelo_vector, a.vector, anterior.version from public.afirmaciones a where a.vector is not null;
  insert into public.huellas_anteriores (prueba_id, tema_id, modelo, vector, version_calibracion)
  select p_prueba, t.id, t.modelo_centroide, t.centroide, anterior.version from public.temas t;

  -- The new model is vigente from here on, so the stamp triggers accept what follows.
  select max(version) + 1 into nueva from public.calibraciones_de_parecido;
  update public.calibraciones_de_parecido set vigente = false where version = anterior.version;
  insert into public.calibraciones_de_parecido
    (version, modelo, tema, grupo, fusion, puente_min, puente_max, vigente, prueba_id, motivo)
  values (
    nueva, prueba.modelo,
    (prueba.umbrales ->> 'tema')::numeric, (prueba.umbrales ->> 'grupo')::numeric,
    (prueba.umbrales ->> 'fusion')::numeric, (prueba.umbrales ->> 'puente_min')::numeric,
    (prueba.umbrales ->> 'puente_max')::numeric,
    true, p_prueba, 'Traslado por percentil de la prueba ' || p_prueba
  );

  update public.afirmaciones a set vector = h.vector, modelo_vector = h.modelo
  from public.huellas_candidatas h
  where h.prueba_id = p_prueba and h.afirmacion_id = a.id and a.vector is not null;

  -- Centroids: the plain mean of the new vectors (20261003000351), which also counts claims assigned after the dry
  -- run; then a merged topic takes the centroid of the topic it points at.
  update public.temas t set centroide = m.media, modelo_centroide = prueba.modelo
  from (
    select a.tema_id, extensions.avg(a.vector) as media
    from public.afirmaciones a
    where a.tema_id is not null and not a.excluida and a.vector is not null
    group by a.tema_id
  ) m
  where t.id = m.tema_id;
  update public.temas t set centroide = d.centroide, modelo_centroide = prueba.modelo
  from public.temas d
  where t.fusionado_en = d.id and t.modelo_centroide <> prueba.modelo and d.modelo_centroide = prueba.modelo;
  if exists (select 1 from public.temas where modelo_centroide <> prueba.modelo) then
    raise exception using errcode = '22023', message = 'falta_centroide';
  end if;

  update public.pruebas_de_modelo
     set estado = 'aplicada', aplicada_en = now(), version_anterior = anterior.version
   where id = p_prueba;
  return jsonb_build_object(
    'asignaciones_antes', antes, 'asignaciones_despues', public.huella_de_asignaciones(), 'version', nueva);
end $$;

create function public.revertir_prueba_de_modelo(p_prueba uuid) returns jsonb
language plpgsql security definer set search_path = '' as $$

  prueba public.pruebas_de_modelo;

  anterior public.calibraciones_de_parecido;
  antes text;
begin
  select * into prueba from public.pruebas_de_modelo where id = p_prueba for update;
  if not found then
    raise exception using errcode = 'P0002', message = 'prueba_inexistente';
  end if;
  if prueba.estado <> 'aplicada' then
    raise exception using errcode = '22023', message = 'prueba_no_aplicada';
  end if;
  if prueba.aplicada_en < now() - interval '30 days' then
    raise exception using errcode = '22023', message = 'plazo_vencido';
  end if;
  select * into actual from public.calibraciones_de_parecido where vigente for update;
  if actual.prueba_id is distinct from p_prueba then
    raise exception using errcode = '22023', message = 'no_es_la_vigente';
  end if;
  select * into anterior from public.calibraciones_de_parecido where version = prueba.version_anterior;
  lock table public.afirmaciones, public.temas in share row exclusive mode;
  if exists (
    select 1 from public.afirmaciones a
    where a.vector is not null
      and not exists (select 1 from public.huellas_anteriores h where h.prueba_id = p_prueba and h.afirmacion_id = a.id)
  ) then
    raise exception using errcode = '22023', message = 'faltan_anteriores';
  end if;
  antes := public.huella_de_asignaciones();

  update public.calibraciones_de_parecido set vigente = false where version = actual.version;
  update public.calibraciones_de_parecido set vigente = true where version = anterior.version;

  update public.afirmaciones a set vector = h.vector, modelo_vector = h.modelo
  from public.huellas_anteriores h
  where h.prueba_id = p_prueba and h.afirmacion_id = a.id and a.vector is not null;

  -- Centroids: exactly the saved one where the topic existed; a topic born after the switch takes the mean of its
  -- restored claims; a merged one, the centroid of the topic it points at.
  update public.temas t set centroide = h.vector, modelo_centroide = h.modelo
  from public.huellas_anteriores h
  where h.prueba_id = p_prueba and h.tema_id = t.id;
  update public.temas t set centroide = m.media, modelo_centroide = anterior.modelo
  from (
    select a.tema_id, extensions.avg(a.vector) as media
    from public.afirmaciones a
    where a.tema_id is not null and not a.excluida and a.vector is not null
    group by a.tema_id
  ) m
  where t.id = m.tema_id and t.modelo_centroide <> anterior.modelo;
  update public.temas t set centroide = d.centroide, modelo_centroide = anterior.modelo
  from public.temas d
  where t.fusionado_en = d.id and t.modelo_centroide <> anterior.modelo and d.modelo_centroide = anterior.modelo;
  if exists (select 1 from public.temas where modelo_centroide <> anterior.modelo) then
    raise exception using errcode = '22023', message = 'falta_centroide';
  end if;

  update public.pruebas_de_modelo set estado = 'revertida', revertida_en = now() where id = p_prueba;
  return jsonb_build_object(
    'asignaciones_antes', antes, 'asignaciones_despues', public.huella_de_asignaciones(), 'version', anterior.version);
end $$;

-- Nightly: saved vectors live 30 days after a switch (the revert window); candidates go with a discarded dry run or
-- 30 days after it was made.
create function public.limpiar_huellas_de_prueba(p_ahora timestamptz) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  anteriores int;
  candidatas int;
begin
  delete from public.huellas_anteriores h using public.pruebas_de_modelo p
   where h.prueba_id = p.id and p.aplicada_en < p_ahora - interval '30 days';
  get diagnostics anteriores = row_count;
  delete from public.huellas_candidatas h using public.pruebas_de_modelo p
   where h.prueba_id = p.id and (p.estado = 'descartada' or p.creada_en < p_ahora - interval '30 days');
  get diagnostics candidatas = row_count;
  return jsonb_build_object('anteriores', anteriores, 'candidatas', candidatas);
end $$;
```

```ts
import type { SupabaseClient } from "@supabase/supabase-js"
import { z } from "zod"
import { type Calibracion, MODELOS_DE_HUELLAS } from "@/lib/dominio/parecido"
import { falloDeBase } from "@/lib/ingesta/gasto-material"
import type { Database } from "@/lib/supabase/database.types"

type Db = SupabaseClient<Database>

const Fila = z.object({
  version: z.number().int(),
  modelo: z.enum(MODELOS_DE_HUELLAS),
  tema: z.coerce.number(),
  grupo: z.coerce.number(),
  fusion: z.coerce.number(),
  puente_min: z.coerce.number(),
  puente_max: z.coerce.number(),
})

/**
 * The vigente calibration (or a given version): the model every embed uses and the thresholds every similarity test
 * reads. Callers read it once per run and pass it down.
 */
export async function leerCalibracion(db: Db, version?: number): Promise<Calibracion> {
  const consulta = db
    .from("calibraciones_de_parecido")
    .select("version, modelo, tema, grupo, fusion, puente_min, puente_max")
  const { data, error } = await (version === undefined ? consulta.eq("vigente", true) : consulta.eq("version", version)).single()
  if (error) throw falloDeBase("No pude leer la calibración de parecido", error)
  const f = Fila.parse(data)
  return {
    version: f.version,
    modelo: f.modelo,
    tema: f.tema,
    grupo: f.grupo,
    fusion: f.fusion,
    puenteMin: f.puente_min,
    puenteMax: f.puente_max,
  }
}
```

```ts
  type TemaParaPrueba,
  umbralesDe,
} from "@/lib/dominio/parecido"
import { PausaDeProveedor } from "@/lib/dominio/pausas"
import { estimarEmbebido, TEXTOS_POR_EMBEBIDO } from "@/lib/ingesta/afirmar"
import { parsearVector, textoDeVector } from "@/lib/ingesta/agrupar"
import { falloDeBase, pagarPaso, redondear } from "@/lib/ingesta/gasto-material"

import type { Almacen } from "@/lib/proveedores/almacen"
import type { Notificador } from "@/lib/proveedores/avisos"
import { costoVoyage, embeber } from "@/lib/proveedores/voyage"
import type { Database } from "@/lib/supabase/database.types"

type Db = SupabaseClient<Database>

/** What the three model tasks need: a `service_role` client, the store, the notices (pauses), the clock and Voyage's key. */
export interface DepsModelo {
  db: Db
  almacen: Almacen
  avisos: Notificador
  ahora: () => string
  llaveVoyage: () => string | undefined
}

export const OMITIDA_POR_PAUSA = { omitida: "voyage_en_pausa" } as const

// Rows of 1024 floats: a page of 200 is a few MB of JSON, an insert of 50 well under any request limit.
const PAGINA = 200
const FILAS_POR_INSERCION = 50

export async function voyageEnPausa(db: Db): Promise<boolean> {
  return (await leerPausasAbiertas(db)).includes("voyage")
}

export function exigirLlave(deps: Pick<DepsModelo, "llaveVoyage">): string {
  const llave = deps.llaveVoyage()
  if (!llave) throw new FallaDeConfiguracion("Falta VOYAGE_API_KEY en este ambiente de Trigger.dev.")
  return llave
}

/**
 * Embeds `textos` with `modelo` in requests of 128, each one reserved and confirmed in `gastos`. The month's limit
 * fails the run: half a set of vectors is worth nothing. A provider pause is opened (WAV is emailed once) and rethrown.
 */
export async function embeberPagando(
  deps: DepsModelo,
  entrada: { llave: string; modelo: ModeloDeHuellas; textos: readonly string[]; paso: "probar" | "aplicar" | "revertir" },
): Promise<{ vectores: number[][]; costoUsd: number }> {
  const vectores: number[][] = []
  let costoUsd = 0
  try {
    for (let desde = 0; desde < entrada.textos.length; desde += TEXTOS_POR_EMBEBIDO) {
      const lote = entrada.textos.slice(desde, desde + TEXTOS_POR_EMBEBIDO)
      const pagado = await pagarPaso(
        {
          db: deps.db,
          almacen: deps.almacen,
          ahora: deps.ahora,
          clave: () => `modelo:${entrada.paso}:${crypto.randomUUID()}`,
          verificar: () => Promise.resolve(),
        },
        {
          proveedor: "voyage",
          paso: "embedding",
          estimadoUsd: estimarEmbebido(lote),
          llamar: async () => {
            const r = await embeber({ clave: entrada.llave, textos: lote, tipo: "document", modelo: entrada.modelo })
            const usd = costoVoyage(r.tokens, entrada.modelo)
            return { datos: { vectores: r.vectores, usd }, realUsd: usd }
          },
        },
      )
      if (pagado.limite) {
        throw new FallaDeConfiguracion("El límite de gasto del mes no deja embeber: súbelo en Ajustes › Presupuesto o espera al mes que viene.")
      }
      vectores.push(...pagado.datos.vectores)
      costoUsd += pagado.datos.usd
    }
  } catch (error) {
    if (error instanceof PausaDeProveedor) await abrirPausa(deps, error)
    throw error
  }
  return { vectores, costoUsd }
}

type FilaConVector = { id: string; texto: string; tema_id: string | null; excluida: boolean; vector: string }

async function leerAfirmacionesConVector(db: Db): Promise<FilaConVector[]> {
  const filas: FilaConVector[] = []
  for (let desde = 0; ; desde += PAGINA) {
    const { data, error } = await db
      .from("afirmaciones")
      .select("id, texto, tema_id, excluida, vector")
      .not("vector", "is", null)
      .order("id")
      .range(desde, desde + PAGINA - 1)
    if (error) throw falloDeBase("No pude leer las afirmaciones con vector", error)
    for (const f of data) if (f.vector) filas.push({ ...f, vector: f.vector })
    if (data.length < PAGINA) return filas
  }
}

async function leerTemas(db: Db): Promise<TemaParaPrueba[]> {
  const temas: TemaParaPrueba[] = []
  for (let desde = 0; ; desde += PAGINA) {
    const { data, error } = await db
      .from("temas")
      .select("id, nombre, fusionado_en, centroide")
      .order("id")
      .range(desde, desde + PAGINA - 1)
    if (error) throw falloDeBase("No pude leer los temas", error)
    for (const t of data) {
      temas.push({ id: t.id, nombre: t.nombre, fusionadoEn: t.fusionado_en, viejo: parsearVector(t.centroide) })
    }
    if (data.length < PAGINA) return temas
  }
}

async function leerRechazadas(db: Db): Promise<{ a: string; b: string }[]> {
  const { data, error } = await db.from("temas_fusion_rechazada").select("tema_a, tema_b")
  if (error) throw falloDeBase("No pude leer las fusiones rechazadas", error)
  return data.map((r) => ({ a: r.tema_a, b: r.tema_b }))
}

/** Inserts candidates in small requests; a claim that already has one for this dry run is left as it is. */
export async function insertarCandidatas(
  db: Db,
  prueba: string,
  modelo: ModeloDeHuellas,
  filas: readonly { id: string; vector: readonly number[] }[],
): Promise<void> {
  for (let desde = 0; desde < filas.length; desde += FILAS_POR_INSERCION) {
    const lote = filas.slice(desde, desde + FILAS_POR_INSERCION)
    const { error } = await db.from("huellas_candidatas").upsert(
      lote.map((f) => ({ prueba_id: prueba, afirmacion_id: f.id, modelo, vector: textoDeVector(f.vector) })),
      { onConflict: "prueba_id,afirmacion_id", ignoreDuplicates: true },
    )
    if (error) throw falloDeBase("No pude guardar las huellas candidatas", error)
  }
}

async function guardarPrueba(
  db: Db,
  entrada: { modelo: ModeloDeHuellas; informe: InformeDePrueba; afirmaciones: readonly AfirmacionParaPrueba[] },
): Promise<string> {
  const u = umbralesDe(entrada.informe.umbrales)
  const { data, error } = await db
    .from("pruebas_de_modelo")
    .insert({
      modelo: entrada.modelo,
      umbrales: { tema: u.tema, grupo: u.grupo, fusion: u.fusion, puente_min: u.puenteMin, puente_max: u.puenteMax },
      informe: entrada.informe,
    })
    .select("id")
    .single()
  if (error) throw falloDeBase("No pude guardar la prueba", error)
  try {
    await insertarCandidatas(db, data.id, entrada.modelo, entrada.afirmaciones.map((a) => ({ id: a.id, vector: a.nuevo })))
  } catch (falla) {
    // Half a dry run must never look ready to apply: it goes, and the run fails with the original error.
    const borrada = await db.from("pruebas_de_modelo").delete().eq("id", data.id)
    if (borrada.error) console.error(`No pude borrar la prueba a medias ${data.id}: ${borrada.error.message}`)
    throw falla
  }
  return data.id
}

export type ResultadoDePrueba = typeof OMITIDA_POR_PAUSA | { prueba: string; informe: InformeDePrueba; texto: string }

/**
 * The dry run of `probar-modelo-de-huellas`: every claim with a vector embedded with `modelo` into `huellas_candidatas`,
 * the thresholds moved by percentile and the report. Nothing Coni uses changes. Voyage failing writes nothing.
 */
export async function probarModeloDeHuellas(
  deps: DepsModelo,
  entrada: { modelo: ModeloDeHuellas },
): Promise<ResultadoDePrueba> {
  if (await voyageEnPausa(deps.db)) return OMITIDA_POR_PAUSA
  const llave = exigirLlave(deps)
  const vigente = await leerCalibracion(deps.db)
  if (vigente.modelo === entrada.modelo) {
    throw new FallaDeConfiguracion(`${entrada.modelo} ya es el modelo vigente: no hay nada que probar.`)
  }
  const filas = await leerAfirmacionesConVector(deps.db)
  const { vectores, costoUsd } = await embeberPagando(deps, {
    llave,
    modelo: entrada.modelo,
    textos: filas.map((f) => f.texto),
    paso: "probar",
  })
  const afirmaciones: AfirmacionParaPrueba[] = filas.map((f, i) => {
    const nuevo = vectores[i]
    if (!nuevo) throw new Error("Voyage no devolvió un vector por afirmación.")
    return { id: f.id, texto: f.texto, temaId: f.tema_id, excluida: f.excluida, viejo: parsearVector(f.vector), nuevo }
  })
  const temas = await leerTemas(deps.db)
  const nuevos = centroidesNuevos(temas, afirmaciones)
  const traslado = calcularUmbrales(muestrasDeParecido(afirmaciones, temas, nuevos), vigente)
  const informe = armarInforme({
    vigente,
    modelo: entrada.modelo,
    traslado,
    afirmaciones,
    temas,
    nuevos,
    rechazadas: await leerRechazadas(deps.db),
    costoUsd: redondear(costoUsd),
  })
```

```ts
import { z } from "zod"
import { leerCalibracion } from "@/lib/datos/huellas"
import { FallaDeConfiguracion } from "@/lib/dominio/falla"
import { MODELOS_DE_HUELLAS, type ModeloDeHuellas } from "@/lib/dominio/parecido"
import { textoDeVector } from "@/lib/ingesta/agrupar"
import { falloDeBase, redondear } from "@/lib/ingesta/gasto-material"
import {
  type DepsModelo,
  embeberPagando,
  exigirLlave,
  insertarCandidatas,
  OMITIDA_POR_PAUSA,
  voyageEnPausa,
} from "@/lib/modelo/probar"

/** A material processed between the top-up and the switch can leave one claim behind: top up and try again. */
const INTENTOS = 3
const FILAS_POR_INSERCION = 50

const Cambio = z.object({ asignaciones_antes: z.string(), asignaciones_despues: z.string(), version: z.number() })
const Prueba = z.object({
  modelo: z.enum(MODELOS_DE_HUELLAS),
  estado: z.string(),
  version_anterior: z.number().nullable(),
})

export type ResultadoDeCambio =
  | typeof OMITIDA_POR_PAUSA
  | {
      prueba: string
      modelo: ModeloDeHuellas
      version: number
      /** Claims embedded during this run (they arrived after the dry run, or after the switch for a revert). */
      embebidas: number
      costoUsd: number
      /** The fingerprint of every assignment, taken inside the transaction, did not change. */
      asignacionesIntactas: boolean
    }

type Destino = "candidata" | "anterior"

async function leerPrueba(deps: DepsModelo, prueba: string): Promise<z.infer<typeof Prueba>> {
  const { data, error } = await deps.db
    .from("pruebas_de_modelo")
    .select("modelo, estado, version_anterior")
    .eq("id", prueba)
    .single()
  if (error) throw falloDeBase(`No pude leer la prueba ${prueba}`, error)
  return Prueba.parse(data)
}

async function insertarAnteriores(
  deps: DepsModelo,
  prueba: string,
  modelo: ModeloDeHuellas,
  version: number,
  filas: readonly { id: string; vector: readonly number[] }[],
): Promise<void> {
  for (let desde = 0; desde < filas.length; desde += FILAS_POR_INSERCION) {
    const lote = filas.slice(desde, desde + FILAS_POR_INSERCION)
    const { error } = await deps.db.from("huellas_anteriores").upsert(
      lote.map((f) => ({
        prueba_id: prueba,
        afirmacion_id: f.id,
        modelo,
        vector: textoDeVector(f.vector),
        version_calibracion: version,
      })),
      { onConflict: "prueba_id,afirmacion_id", ignoreDuplicates: true },
    )
    if (error) throw falloDeBase("No pude guardar las huellas anteriores", error)
  }
}

/** Embeds the claims that still lack their row for `destino` and inserts them. */
async function completar(
  deps: DepsModelo,
  e: { prueba: string; destino: Destino; modelo: ModeloDeHuellas; version: number; llave: string },
): Promise<{ embebidas: number; costoUsd: number }> {
  const { data, error } = await deps.db.rpc("afirmaciones_sin_huella", { p_prueba: e.prueba, p_destino: e.destino })
  if (error) throw falloDeBase("No pude buscar las afirmaciones sin huella", error)
  if (data.length === 0) return { embebidas: 0, costoUsd: 0 }
  const { vectores, costoUsd } = await embeberPagando(deps, {
    llave: e.llave,
    modelo: e.modelo,
    textos: data.map((f) => f.texto),
    paso: e.destino === "candidata" ? "aplicar" : "revertir",
  })
  const filas = data.map((f, i) => {
    const vector = vectores[i]
    if (!vector) throw new Error("Voyage no devolvió un vector por afirmación.")
    return { id: f.id, vector }
  })
  if (e.destino === "candidata") await insertarCandidatas(deps.db, e.prueba, e.modelo, filas)
  else await insertarAnteriores(deps, e.prueba, e.modelo, e.version, filas)
  return { embebidas: filas.length, costoUsd }
}

async function cambiar(
  deps: DepsModelo,
  e: { prueba: string; destino: Destino; modelo: ModeloDeHuellas; version: number; llave: string },
): Promise<ResultadoDeCambio> {
  const falta = e.destino === "candidata" ? "faltan_candidatas" : "faltan_anteriores"
  let embebidas = 0
  let costoUsd = 0
  for (let intento = 1; ; intento++) {
    const hecho = await completar(deps, e)
    embebidas += hecho.embebidas
    costoUsd += hecho.costoUsd
    const { data, error } =
      e.destino === "candidata"
        ? await deps.db.rpc("aplicar_prueba_de_modelo", { p_prueba: e.prueba })
        : await deps.db.rpc("revertir_prueba_de_modelo", { p_prueba: e.prueba })
    if (!error) {
      const r = Cambio.parse(data)
      return {
        prueba: e.prueba,
        modelo: e.modelo,
        version: r.version,
        embebidas,
        costoUsd: redondear(costoUsd),
        asignacionesIntactas: r.asignaciones_antes === r.asignaciones_despues,
      }
    }
    if (!error.message.includes(falta) || intento >= INTENTOS) throw falloDeBase("No pude cambiar el modelo", error)
  }
}

/** `aplicar-modelo-de-huellas`: after Federico's OK, the dry run becomes the live model in one transaction. */
export async function aplicarModeloDeHuellas(deps: DepsModelo, entrada: { prueba: string }): Promise<ResultadoDeCambio> {
  if (await voyageEnPausa(deps.db)) return OMITIDA_POR_PAUSA
  const llave = exigirLlave(deps)
  const prueba = await leerPrueba(deps, entrada.prueba)
  if (prueba.estado !== "lista") {
    throw new FallaDeConfiguracion(`La prueba ${entrada.prueba} está ${prueba.estado}: solo se aplica una prueba lista.`)
  }
  return cambiar(deps, { prueba: entrada.prueba, destino: "candidata", modelo: prueba.modelo, version: 0, llave })
}

/** `revertir-modelo-de-huellas`: within 30 days of the switch, everything goes back to the model of before. */
export async function revertirModeloDeHuellas(deps: DepsModelo, entrada: { prueba: string }): Promise<ResultadoDeCambio> {
  if (await voyageEnPausa(deps.db)) return OMITIDA_POR_PAUSA
  const llave = exigirLlave(deps)
  const prueba = await leerPrueba(deps, entrada.prueba)
  if (prueba.estado !== "aplicada" || prueba.version_anterior === null) {
    throw new FallaDeConfiguracion(`La prueba ${entrada.prueba} está ${prueba.estado}: solo se revierte una prueba aplicada.`)
  }
  const anterior = await leerCalibracion(deps.db, prueba.version_anterior)
  return cambiar(deps, { prueba: entrada.prueba, destino: "anterior", modelo: anterior.modelo, version: anterior.version, llave })
}
```
